AI算力終將被用盡，但資產的主人很可能會換人

上一輪光纖泡沫裡，負債最重的公司率先破產，但光纖資產被別人接手後照樣好用；Mike Volpi 認為這輪 GPU 建設會重演同一劇本——資產會被充分利用，歸屬權卻很可能換人。

帶寬靠技術躍進，算力只能喝摩爾定律的湯

90年代的光纖靠 WDM（波分複用）技術，在同一根光纖裡塞進更多顏色的光，帶寬一下子能翻40到80倍；這次 AI 算力擴容完全不同，受摩爾定律約束，提升速度反而更慢。Mike Volpi 認為這是這輪建設和互聯網建設最根本的技術差異之一——供給增長的節奏完全不是一回事。

— Mike Volpi
6:14

資產會被用盡，但主人很可能換人

Mike Volpi 回顧互聯網泡沫：當年負債最重的公司最先破產，但他們買下的光纖資產並沒有跟著消失，而是被別人低價接手繼續使用。他認為這輪 AI 建設會重演同樣的劇本——數據中心和芯片一定會被充分利用，甚至超出預期，但誰擁有這些資產，很可能不是今天砸錢建設的這批公司。

— Mike Volpi
11:33

H100該報廢了，租金卻反而漲價

四年前業內普遍認為 H100 這類芯片大概只有五年壽命，當時每 GPU 小時租價約1.82美元。按理說快到壽命盡頭該掉價，但現實是它現在能以每小時2.5到3美元出租——比當初還貴。Mike Volpi 把這歸因於算力極度稀缺：只要半導體制造產能跟不上需求，老芯片就會持續被需要，資產壽命比融資模型假設的要長得多。

— Mike Volpi
14:43

思科的併購哲學：允許三分之一徹底打水漂

Mike Volpi 回憶思科當年做併購的方法：把結果大致分成三份——三分之一效果很好、三分之一平平、三分之一徹底失敗，公司能接受失敗率，只要做的次數夠多就能撞上幾個真正的大贏家，有的收購花5億美元，兩年後利潤就做到10億美元。到2000年前後，思科收入的一半來自被收購的業務，且單筆收購很少超過公司市值的4%到5%。

— Mike Volpi
19:54

英偉達砸錢扶持新雲廠商，終究是徒勞

針對 NVIDIA 投資大量 neocloud（新興 GPU 雲廠商）以培養更多買家的做法，Mike Volpi 認為這改變不了行業最終的格局：凡是規模效應主導的行業，無論給小玩家輸多少錢，最後都會收斂成少數幾家巨頭，就像美國航空業最終只剩三大航司。NVIDIA 這麼做不是為了財務回報，而是不想只有三四個大客戶可以談判，但這終究是在延緩而非改變行業的自然演化方向。

— Mike Volpi
34:09

模型路由興起，token價格差距高達5到7倍

過去兩年行業默認只用最頂級的前沿模型 token，但 Mike Volpi 觀察到市場正在變聰明：頂級 Anthropic token 和頂級 Kimi token 之間的價格差能到5倍甚至7倍，這個差距巨大到足以催生「模型路由器」（按任務難度把請求分流到不同價位模型的系統）這門新生意。他認為這會讓AI的總需求開始對價格產生敏感度，而不是像過去那樣無腦追最貴的模型。

— Mike Volpi
43:27

訂單泡沫一碰就碎：思科六個月市值跌到十分之一

Mike Volpi 復盤思科當年的崩盤：由於交付週期緊張，客戶習慣性地超量下單以防被削減配額，思科也因此把風險轉嫁給供應鏈、提前打款囤貨。等真實需求一降溫，訂單直接砍到四分之一，疊加供應鏈上已經付出的風險，公司營收單季度就錯失了35%到40%，股價從80多美元跌到9美元，六個月內縮水到十分之一。

— Mike Volpi
47:45

AI數據中心該拋棄統計複用，改用確定性電路

互聯網時代的交換機設計建立在流量忽高忽低、靠統計複用削峰填谷的假設上；但AI數據中心裡GPU永遠滿載、流量高度可預測，尤其訓練階段幾乎完全確定。Mike Volpi 認為今天主流的 Broadcom Tomahawk 這類統計複用架構其實是「帶寬夠用但架構不對」，真正該出現的是假設全時滿載、不需要緩衝區的全新交換架構，而這正是經典的創新者窘境——現有廠商不會主動革自己的命，機會留給敢 all in 新架構的新進入者。

— Mike Volpi
