沒有 Claude Code，Anthropic 是另一家公司

雨森認為 Anthropic 被擔心成「賣 API 的公司」時，真正的轉折是 Claude Code。它帶來大量高質量使用數據，數據迴流讓 coding 模型更好，形成數據飛輪。而 Codex 後來漲得也猛，說明 Claude Code、Codex 本質都是 Harness——不是有了強模型就能把 API 賣出去，用戶要的是一個產品，不是 API。

23:17

Anthropic 的收入不是回報，是客戶的投入

雨森把鏈條拆成投入、產出、結果三步：買 Token 是投入，做出軟件是產出，軟件賣錢或降本才是結果。Anthropic 收入大漲讓很多人以為回報問題解決了，但這是把問題下推給了它的客戶。他反問：一個公司突然多十倍工程師，收入會大漲嗎？目前沒觀察到結果端的大幅提升，因為缺的不是程序員，是不知道該做什麼。

— 戴雨森
37:14

殼早就不是殼：model、harness、context、runtime

雨森用 F1 打比方：模型是車手，Harness 是保養換胎讓它留在賽道里的一整套。分層是模型、context、工具與 agentic loop、runtime/sandbox。OpenClaw 之所以驚豔，是給了模型很多權限，還有心跳機制每 30 分鐘檢查有沒有沒做完的事。這些機制講出來都簡單，但讓模型在長任務上完成得更好。價值越來越多在模型外面包的這幾層殼裡。

— 戴雨森
52:25

Harness 更像 OS，模型更像處理器

廣密說模型公司是新生代 OS，雨森不同意：Harness 本身更像 OS，模型像驅動 OS 的處理器。Windows 時代你可以插 Intel 也可以插 AMD，哪個便宜好用用哪個；現在用戶也可以給 Harness 插拔模型。做 Skill 的人不用處理怎麼跟模型通訊，就像 Windows 出現後開發者不用 handle 硬件，只 handle API。

— 戴雨森
59:20

agent 之間可能出現網絡效應

過去 AI 一直沒有好的網絡效應，因為六個月前你用 Claude Code、我用 Claude Code 沒有本質差別，沒理由交換。但現在 Harness 裡沉澱了各自的 context 和 skills，同一個任務給不同人的 agent 做結果不同。於是可能出現「我的 agent 僱傭張耀俊的 agent」：付 1 萬塊，1000 塊是 token 價值，9000 塊是對方 agent 積累的專有知識。這種價值網絡有點像電商，但還很早。

— 戴雨森
1:21:26

你原來的護城河會變成軟肋

移動互聯網的超級應用把用戶圈在 APP 裡形成閉環，但如果用戶的 agent 訪問不到封閉 APP 裡的信息，這個閉環就變成束縛。微信不開放，飛書開放還出了飛書 CLI，於是人有動力把工作群從微信遷到飛書——在微信裡聊 agent 看不到，在飛書裡聊 agent 看得到。同時大公司對安全質量要求高，而 OpenClaw 這類產品沒有歷史包袱，可以針對前沿用戶設計更 AI native 的交互。

— 戴雨森
1:28:51

AI 像外星人來到人類世界，分三步

第一步讓人類擁有更多更好的 agent（Claude Code、Codex、Manus 都在做）；第二步讓 agent 適應人類的數字世界——人類的數據世界是為人類設計的，GUI、驗證碼、信用卡原本都是用來擋 Bot 的，現在要給 AI 發卡、讓 agent 平等註冊使用服務；第三步是建設 agent 專屬的數字世界，比如 agent 之間的支付是高頻、小額、多對多的，可能根本沒有卡的概念，而是 CLI 或 API。每一步都是產品機會。

— 戴雨森
1:38:51

下一個字節可能長得不像字節

雨森說很多 AI 應用是「AI 的信息流」：一打開也是信息流，用戶單列雙列刷 AI 產生的東西，本質是把新技術包進字節最擅長的殼裡，再比推廣分發。在字節的遊戲規則裡打敗字節非常難。OpenClaw 是另一種形態：沒有自己的應用，連陣地都沒有，但活在每個地方。把上個時代的成功範式搬到 AI 時代，等於跟冠軍正面競爭。

— 戴雨森

模型外面包的一整套工具、context、agentic loop 與 runtime，讓強模型按規矩跑。
context engineering上下文工程
把模型不知道的實時信息、組織專有信息餵給模型的那層工作。
sandbox沙盒
給 agent 上網、用軟件、跑任務的隔離運行環境。
