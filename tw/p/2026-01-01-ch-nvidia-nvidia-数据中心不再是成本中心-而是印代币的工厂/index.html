NVIDIA：數據中心不再是成本中心，而是印代幣的工廠

摩爾定律的物理紅利早已終結，NVIDIA 靠在能源、芯片、基礎設施、模型、應用五層之間做「極致協同設計」，把每瓦、每美元能產出的token數硬拉上去。

算力基礎設施數據中心液冷與能源AI代理存儲架構NVIDIA
技術細節密度高（液冷、銅纜極限、光學互聯、代理記憶架構），適合想理解AI工廠底層工程邏輯的人；對只關心商業敘事的讀者信息量一般。

3:09

數據中心從花錢的IT成本中心變成印鈔機

演講開場就把範式轉換講清楚：過去數據中心是跑IT應用、純花錢的成本中心；AI工廠則必須高效生成token來創造收入。這個定位轉變，是後面所有工程決策（能源、芯片、冷卻）的出發點——一切優化都是為了拉高「每美元/每瓦token數」。

— Kevin Deierling
4:09

摩爾定律的物理約束早在二十年前就斷了

晶體管數量確實還在翻倍，但摩爾定律原本還包含「同功耗、同成本翻倍」的物理與經濟承諾，這部分在2005年前後的Dennard scaling終結後就已失效。這是NVIDIA押注加速計算、把單線程應用重寫為GPU並行應用的根本原因，而不是單純的營銷敘事。

— Kevin Deierling
6:13

混合專家模型一出現，token消耗量直接跳升

模型參數每年增長約10倍是穩定趨勢，但一年半前混合專家（MoE）模型帶來一個拐點：模型開始「推理」，為生成一個輸出token，內部會多生成多達100倍的token。代理（agent）的到來會讓這個需求進一步加速增長，這也是為什麼NVIDIA要持續把每token成本壓低。

— Kevin Deierling
13:31

用「水庫調峰」思路給AI訓練的電力曲線削峰填谷

AI訓練時成千上萬GPU像一臺巨型計算機同步做集合通信，電力負載像暴雨一樣忽高忽低，會打壞供電變壓器。NVIDIA用DSX Flex/DSX LPS這類儲能系統把多餘電能存起來，在用電高峰時釋放，把消耗曲線拉平。這個單項優化讓同樣一吉瓦電力下能多部署40%的GPU，直接等於多40%的收入。

— Kevin Deierling
16:38

推理遠比想像中複雜，單芯片設計已經不夠用

外界曾普遍認為推理會比訓練簡單，但MoE模型對NVLink縱向擴展和跨機架橫向擴展都提出了高要求，代理工作負載還會進一步加碼。NVIDIA的回應是把Rubin GPU、Vera CPU通過芯片到芯片的高性能、緩存一致互聯緊耦合，再用NVLink在機櫃內擴展、Spectrum-6在數據中心間擴展，宣稱這樣做能帶來10倍token吞吐和十分之一的單token成本。

— Kevin Deierling
19:43

銅線信號從芯片出來就被PCB上的銅線搞「醜」了

為了省電，NVIDIA堅持「能用銅就用銅」，但高速信號過銅纜只能傳幾米，所以才把GPU硬擠進同一個機櫃並上液冷。更反直覺的是：即便在機架內部，信號走過PCB上那段短短的銅線也會劣化，所以需要重新放大、再驅動光學模塊；而共封裝光學（CPO）交換機直接把光學器件焊在ASIC旁邊，省掉這段劣化過程，能在AI工廠裡省下數十兆瓦的電——這些電省下來就能拿去多生成token。

— Kevin Deierling
21:46

代理是「AI在吃自己的尾巴」，不再需要人類慢吞吞地發提示

代理的本質是AI把輸出反饋給自己形成閉環，不再依賴人類輸入提示詞——而人類太慢、AI太快也太「沒耐心」，於是出現AI對AI對話的鏈條。Vera CPU就是專門為跑這種代理工具鏈設計的：規劃、寫程序、總結並壓縮結果，這也直接推高了對內存和互聯帶寬的需求（文中提到800G升級到1600G/秒）。

— Kevin Deierling
22:46

代理需要「短期記憶+長期記憶」，這要求全新的存儲架構

NVIDIA把KV cache類比為代理的短期記憶，文件、對象、向量數據庫類比為長期記憶，併為此設計了CMX（短期）和STX（長期）參考架構。這套新架構據稱帶來5倍的token吞吐和5倍效率提升——存儲不再只是存數據，而是直接決定代理「思考」的速度。

— Kevin Deierling

This extreme co-design delivers 10x more tokens and one-tenth the cost per token by optimizing across this stack. Everybody said that inferencing was going to be easy. It's incredibly complicated.

這種極致協同設計通過在整個技術棧上做優化，帶來了10倍的token產出和十分之一的單token成本。所有人都曾說推理會很簡單，但它其實極其複雜。

Kevin Deierling16:38

So we have to reproduce the electrical signal and make it beautiful again, and then we drive the optics.

所以我們必須重新還原這個電信號、讓它重新變漂亮，然後再去驅動光學模塊。

Kevin Deierling19:43

An agent is AI eating its own tail. Instead of humans generating prompts, AI closes the loop and feeds the prompt back to itself.

代理就是AI在吃自己的尾巴。不再是人類生成提示詞，而是AI自己把提示反饋給自己，形成閉環。

Kevin Deierling21:46

The result of this extreme co-design is five times faster token throughput and five times better efficiency using these new specialized AI storage architectures.

這種極致協同設計的結果是：藉助這些全新的專用AI存儲架構，token吞吐速度提升5倍，效率也提升5倍。

術語

Extreme Co-Design極致協同設計
在能源、芯片、基礎設施、模型、應用五層之間同時做跨層優化，而非單獨優化某一層。
Co-Packaged Optics (CPO)共封裝光學
把光學收發器直接封裝在交換芯片旁邊，減少信號在PCB銅線上的損耗與功耗。
KV CacheKV緩存

Mixture-of-Experts (MoE)混合專家模型
一種讓模型推理時動態調用部分「專家」子網絡的架構，會顯著增加內部token消耗。
NVLinkNVLink互聯
NVIDIA用於機櫃內GPU之間高帶寬互聯的技術，使多塊GPU可協同像一臺計算機運行。
