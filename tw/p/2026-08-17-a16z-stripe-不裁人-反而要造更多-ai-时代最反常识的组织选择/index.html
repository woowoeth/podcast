Stripe 不裁人，反而要造更多：AI 時代最反常識的組織選擇

當所有公司用 AI 優化成本結構時，Stripe 選擇把省下來的工程師產能全部投入新產品——因為優化成本是「做空自己的未來」，而造更多是「做多」。

Stripe 要把自己變成內部創始人的平臺

Will Gabrick 說 Stripe 一直是對外服務創始人的平臺，但現在要變成「內部創始人的平臺」。邏輯是：當單個高級工程師能完成兩年前兩個團隊的工作量時，組織不該縮減，而該讓每個工程師都像創始人一樣有自主權。Stripe 收購的 Metronome、Privy、Bridge、Lemon Squeezy 的創始人們現在都在 Stripe 內部領導重要業務線——Scott Woody 管 billing，Henry 管 crypto，Zach 管 OpenUSD 和 Bridge。這不是巧合，是刻意把創始人放進組織內部當「auteur」來用。

— Will Gabrick
13:54

Minions 一週生成 7000 個 PR，佔全公司 30%

Stripe 內部工具 Minions 的核心設計是「one shot」：給一個 prompt，它直接構建、跑完 CI/CD 和全部測試，然後等人 review——沒有迭代、沒有 planning mode。今年 1、2 月博客發布時是每週 1200 個 PR，上週達到 7000 個，佔 Stripe 當週全部 PR 的 30%。Will 說這就是「glorified RELF loop」，讓 agent 極度強大。配套的組織變化是「flatter, smaller teams」：一個高級工程師現在可以同時 orchestrate 16 個 agent，Stripe Projects 的大部分 PR 就來自一個人。

— Will Gabrick
19:11

優化成本是做空自己，造更多是做多未來

David George 把兩種 AI 策略總結為「long versus short」：優化成本結構是 short 自己的未來潛力，相當於資本配置裡的「返還現金」；而 build more 是 long 未來潛力，相當於「再投資現金」。Will 用內部工具 Kai 舉例：83% 周活、60% 日活，銷售生產力提升 20%，但 Stripe 的反應不是「可以少招銷售」，而是「payback 變好了，應該招更多銷售」。他引用 Jevons paradox：資產變高效後，你要的不是更少，是更多。

— David George / Will Gabrick
25:23

AI 編程像注塑機：先做模具，再批量生產

Will 用注塑機（injection molding）比喻 agentic engineering：二戰後消費品和玩具爆發，是因為 40 年代掌握了均勻熔化塑料並注入金屬模具的螺桿技術。Stripe 現在做代碼生產也一樣——先創建 mold 和 templates，每個 repo 裡放好 agent files，理解與金融機構集成的模式，然後把大量工作交給 agent，人類時間花在 code review 上，而 agent 做 code review 甚至比人更好。結果是 Stripe Tax 的全球 filing 功能只用了美國 filing 三分之一的時間，複雜度還更高。

— Will Gabrick
28:29

Agentic commerce 缺的不是模型，是原語

Will 說 agentic commerce 還沒等到它的「Opus 4.5 Cambrian explosion moment」，因為沒有大量重複出現的 canonical use cases。原因之一是 missing primitives：Stripe 和 Tempo 做了 machine payments protocol，服務方可以返回 402 響應告訴機器怎麼付款。另一個開放問題是 checkout 該長什麼樣——browser automation 讓 agent 爬表單是「skeuomorphic version」，原生版本還沒出現。Will 認為 checkout page 最終會消失，對人類也一樣。

— Will Gabrick
34:37

微交易過去不成立，是因為沒有 agent 當消費者

微交易被討論了幾十年沒成，Will 認為原因是：賣單篇文章永遠被訂閱模式和免費模式兩頭擠壓。但 agent 改變了這個結構——你希望 agent 像蜂鳥一樣在互聯網上到處飛，這裡 slurp 一點數據，那裡做一點臨時計算，人類不該為每個服務創建賬號。同時穩定幣讓微交易第一次變得「eminently possible」：人類用穩定幣要跳一堆坑，但給 agent 一個預算，它可以輕鬆把美元換成穩定幣或使用 stored balance 完成結賬，而且不介意來回折騰。

— Will Gabrick
37:39

穩定幣是更好的全球支付平臺，因為繞開了政治

Will 自稱 infrastructure nerd，說穩定幣就是比現有方案更好的移錢平臺。印度 UPI 上低於 5 美元的支付佔比約 86%，美國信用卡只有個位數百分比——好的廉價快速支付系統大多是國有化的。但全球經濟需要一個「shelling point」，一個所有人都能同意的東西，而 crypto rails 正好解決這個政治問題：這個平臺在哪裡都能用。Stripe 用戶可以用 fiat 在約 60 個國家使用，用穩定幣可以在約 150 個國家使用。

— Will Gabrick
43:43

Token 正在變成錢的近似物，Stripe 要同時管好兩種

Will 說他一直喜歡 token 這個詞，因為它聽起來就像錢的近似物，而且越來越是。Stripe 看到針對通用 token 消費者（Cursor、Replay 等平臺用戶）的攻擊非常 sophisticated，和偷 Stripe 用戶錢的攻擊很像。所以 Stripe 認為自己有 mandate 在 token 上做和美元一樣的事：安全、合規地移動、存儲、發送。Will 把 token 使用分成兩類——build things 的 OPEX 管理，和產品 efficacy 管理（怎麼在不同模型間切換最有效），Stripe 想同時幫用戶管好這兩端。

— Will Gabrick
