繼續出口DUV光刻機，恐讓美國十億芯片產能優勢拱手讓人

智庫該補的是前瞻研究的空當

Khan 說，當年在喬治城 CSET 做半導體政策研究時，AI 政策還沒人關心，有大把時間做面向一兩年後的前瞻研究；如今每天都有AI新消息，反而沒人願意沉下心做這種工作。他認為新智庫 CTS 要補的就是這個空當：一是做一兩三年後真正管用的政策構想，二是把研究建立在真實的供應鏈細節上——從製造設備到 token 到機器人，因為物理世界的東西是可預測的、經得起深挖，不像空對空的政策辯論。

7:04

美國領先8個月，沒人說清機制是什麼

外界常說美國模型能力領先中國約八個月，但 Khan 說這個數字背後的機制幾乎沒人講清楚——多少來自訓練更大模型，多少來自中國公司靠蒸餾或強化學習獲得的能力提升，美國進展加速或放緩又會如何傳導到中國。他舉例，當 GLM 5.3 flash 被曝出用數十萬億 token 訓練時，輿論立刻說「出口管制沒用了」,但這個判斷對不對，其實缺乏系統性的解釋支撐。

— Saif Khan
13:21

DUV光刻機是中國最後一塊啃不下的骨頭

Khan 說，EUV極紫外光刻之外，DUV浸沒式光刻是目前仍在用於製造先進芯片的次優技術，華為造7納米芯片靠的就是它。全球只有日本和荷蘭兩個美國盟友能造這類機臺，是美國手裡最有效的卡脖子工具——中國造不出來，而且是整條半導體設備供應鏈裡最難實現自主可控的一環。報告測算，中國要到2030年代中期左右才可能有商用的本土DUV機臺，是供應鏈裡最後被攻克的環節。

— Saif Khan
17:30

管制留了口子，中國機臺存量已悄悄翻倍

2023年管制生效時，低一檔的DUV浸沒式機臺仍被允許賣往中國，當時中國存量約170到180臺，此後這個存量已大致翻倍。報告建模測算：如果現在徹底切斷DUV出口，到2030年代中期，美國每年能產出約10億顆H100等效AI芯片，而中國本土產能會被鎖死在千萬顆量級；但如果繼續放行這些機臺，兩邊產能區間可能會重疊，等於把整個領先優勢拱手讓出。

— Saif Khan
31:18

軟件智能爆炸之外，機器人是被低估的變量

Khan 認為，未來幾年AI世界真正的轉折點，可能不是軟件上的遞歸自我改進，而是物理世界的自動化——AI與機器人結合，規模化部署機器人去學習製造，最終可能形成自給自足的供應鏈。這個方向目前在華盛頓幾乎是空白地帶，他說整個政策圈裡認真研究機器人與AI交叉問題的人一隻手數得過來，中國那邊的研究更是幾乎沒有，這會是美中AI競爭下一個關鍵節點。

— Saif Khan
33:27

AI政策分裂成安全派與擴散派兩種世界觀

Khan 把AI政策的分歧歸納成兩種思維：「安全心態」認為最重要的行動者是研發前沿模型、可能帶來災難性風險或改變世界權力平衡的少數AI公司，這種變化往往發生在現有建制之外；「擴散心態」則認為真正重要的是AI被廣泛採用後與既有制度的共同演化，核心是財富再分配和AI在經濟體系中的角色。他強調這兩者不是對立，而是都要解決——即便防住了生物武器風險，只要沒回答人類在AI經濟裡扮演什麼角色，問題就還沒解決。

— Saif Khan
44:00

編程智能體把智庫人力壓縮到一小部分

Khan 說，過去九個月裡 Claude Code 和 Codex 這類編程工具，讓CTS這樣的小團隊能查詢大量數據、快速做深度分析，DUV報告能達到的技術分析深度很大程度上得益於此。他認為過去需要十五到二十人的智庫團隊，現在一個更小的團隊就能做到同等的產出密度和分析深度，這也是CTS願意在這類工具上大舉投入的原因。

— Saif Khan
55:36

他不是RSI懷疑論者，但不知道曲線會怎麼彎

面對「你比Dario Amodei更懷疑遞歸自我改進」的說法，Khan否認自己是懷疑論者：他認為AI公司完全有能力判斷自己是否在實現AI研發自動化，未來幾年很可能真的大幅自動化一大部分AI研究。他真正的不確定在於另一個問題——自動化AI研發究竟只是勉強讓人類維持住現有的能力增長曲線，還是會把這條曲線進一步推陡；今年已經出現自主網絡攻擊、智能體能力、解出Navier-Stokes這樣的千禧年數學難題等里程碑，但自動化研發在現實世界的實際影響，他認為現在還很難判斷。

— Saif Khan
