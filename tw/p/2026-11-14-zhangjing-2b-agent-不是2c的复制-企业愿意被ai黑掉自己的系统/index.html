2B Agent 不是2C的複製：企業願意被AI黑掉自己的系統

Afine創始人認為2C的Personal Agent太卷，拼的是供應鏈和補貼；2B Agent因為老闆主動配合AI改造公司，反而更容易端到端捕獲價值。

7:03

百個Agent加百個員工放大的是噪聲

賀佳琛指出，給每個員工配一個Personal Agent後，企業決策層面對的不再是100個員工的信號，而是100個員工加100個Agent，這些Agent之間沒有聯動和學習過程，反而放大的是噪聲而不是信號。他們的解法是讓所有人共用一個具備持續學習能力的Agent，既保留個人單獨的記憶和運行環境，又能在公司所有業務和軟件前臺持續學習。

— 賀佳琛
14:07

2C的Agent幾乎沒有規模效應

賀佳琛認為AI創業與互聯網創業最大的區別是規模效應和網絡效應被極大減弱：做一個聊天機器人，用戶量再大，數據也未必能讓產品進化到更強的Agent，模型本身的智能提升才是決定性因素。這也是他們不做2C Personal Agent的核心原因——2C賽道拼的是供應鏈和補貼，而非產品本身的壁壘。

— 賀佳琛
19:13

B端老闆主動配合AI黑自己的系統

在C端，獲取用戶全部信息去做推薦會讓人恐懼，Personal Agent天然要靠奇技淫巧和逆向工程才能拿到權限；但在B端，企業一號位告訴員工說AI能端到端捋順業務數據、財務數據、每一行代碼流向後，老闆反而有更強動力主動改造自己的系統以配合AI獲取更多context。這使得2B Agent在早期反而更容易獲得採用。

— 賀佳琛
26:20

工作流外掛的生命週期越來越短

賀佳琛談到LongChain、Dify、N8N、Open Cloud這類工作流/腳手架產品曾經估值飛漲，但到26年下半年已經很少被提起。原因不是被更好的工作流取代，而是模型本身把這些工作流學了進去——用更聰明的模型或harness後，第一件事往往是把之前的skill和system prompt刪掉，否則反而起負作用。確定性的固化正從模型外轉向模型內，靠KV Cache和Prompt Cache命中率就能復現確定性輸出。

— 賀佳琛
35:31

自己訓模型在26年才真正可行

賀佳琛曾深度參與國內一個ET參數以上多模態agentic model的訓練，當時認為創業公司做模型訓練根本找不到客戶，因為前沿大廠的卡、人才密度和基建端到端都遠勝第三方。但到26年，隨著架構變化（如Jamba類模型出現）和基模能力達標，小模型可以不追求比AGI model更強，只需把確定能做對的任務以更低成本、更快響應蒸餾出來，這才讓創業公司訓模型變得make sense。

— 賀佳琛
36:32

小模型是植物神經，大模型是大腦皮層

他們訓練兩種模型：一種是Task Routing Model，把sota模型完成任務時的工具調度軌跡和用戶偏好蒸餾下來形成「肌肉記憶」，讓小模型像人學會騎車後形成條件反射；另一種是20到40億參數的Worker Model，專門處理企業內部操作系統層面的逆向和特定任務，突破大模型在安全限制下的侷限。賀佳琛將聰明的大模型比作大腦皮層，自己訓練的小模型則是腦幹和脊髓。

— 賀佳琛
40:34

今天所有軟件本質上都是開源軟件

賀佳琛提出一個判斷：只要別人知道你的軟件在做什麼、能拿到API spec，AI就能把整個軟件逆向出來或重寫一個功能一模一樣的替代品，所以軟件本身在消亡，價值轉向了模型智能本身。他同時預計兩到三年內開源模型追趕速度會大幅加快，AGI模型供給會變得充裕，屆時B端C端重構世界的商業規則會變得非常血腥。

— 賀佳琛
43:34

Agent正在跨越此前陪伴視頻賽道獨享的拐點

賀佳琛認為過去兩三年裡，只有聊天和視頻生成這類交付結果可預期、能商業化閉環的賽道率先賺到錢，而通用Agent因為必須端到端完成才能創造價值，只要缺一環就解鎖不了大價值。但這個環最近被補上，連之前視頻、陪伴賽道積累的優勢也開始被通用基建和通用模型挑戰，他舉例稱Opus 5.5最會剪視頻、GPT6 Astra最會控制機器人視頻，是「倒反天罡」的現象。

— 賀佳琛

Proactive Agent主動型智能體
不只是被動響應對話，還會主動聯繫用戶、推進任務的Agent形態
KV Cache / Prompt Cache鍵值緩存/提示詞緩存
存儲模型此前生成結果，使相同調用可直接複用而不必重新推理
Task Routing Model任務路由模型
將大模型完成任務的軌跡和用戶偏好蒸餾下來、低成本復現的小模型
