AI 不是組織的工具，是組織的替代品

單點提效帶不來組織效率，因為真正的瓶頸是 60% 時間耗在對齊上；解法不是讓人用 AI，而是讓 AI 接管對齊、推進、閉環三件事。

0:01

提效了卻沒多賺錢的鬼故事

很多公司已經進入第二階段：AI 學了也用了，個人提效明顯，但整體效率沒提高，或者效率提高了利潤沒增加，甚至裁員省了錢利潤也沒漲。作者把效率拆成三層：單點任務效率、組織協調效率、市場戰略位置。大部分人只盯第一層，但公司要把個體努力協調成整體效果，第二層遠比第一層重要；而哪怕組織協調做好了，打下來什麼城市、站在什麼生態位，才決定能不能賺錢。

4:30

飛機快 30 分鐘，門到門只省半小時

阿姆達爾定律：一件事有很多環節，只優化其中一個，整體效果有限。上海到北京飛機 130 分鐘，提速 30% 到 100 分鐘是偉大科技進步，但端到端門到門要五個小時，省 30 分鐘對五小時來說變化不大。更慘的是系統表現取決於最瓶頸的環節：洗菜切菜快十倍，灶臺只有四個，整體可能只提升 1%；就算後廚全線提效十倍，門口人流量沒增加，還是賺不到錢。

8:30

60% 白領時間花在對齊上

知識工作最大的消耗不是做事本身，而是開會、對齊、協調、對接、交接、等待。多份報告口徑基本一致：60% 的白領工作時間在做協調性對齊性工作。作者建議翻自己上一週的日曆，看多少時間在開會、多少會是為了溝通協調。工資越高的白領，這種對齊協調和人、信息、人情的交互就越多。火星探測器因為一家用英制、一家用公制，沒對齊，飛了九個半月直接燒在大氣層，一億多美金打水漂——各自做的都對，整體是零。

18:56

AI 不是組織的工具，是替代品

作者提出暴論：AI 原生組織轉型不是把原來的組織轉一轉更好地用 AI，而是想怎麼用 AI 去替代原來組織的絕大部分功能。組織本身是近代發明，用來解決信息路由和管控機制兩個問題。層級是因為一個人看不過來，但滴滴一個人能管上千司機；部門是因為人不是通才，但如果每個人旁邊都有 AI 翻譯，部門設計是否還需要；流程是因為看不到全局，但如果 AI 能看到全局，為什麼還要人來控流程。就像坐月子不洗頭，古人有道理，但熱水器、電吹風、青黴素出現後，前提假設變了。

23:00

N 平方條路徑，靠有損壓縮硬扛

對齊分兩件事：對齊事實（世界是什麼樣子）和對齊打法（我們要怎麼做）。純數學上 N 個人有 N 平方級對齊壓力，三個人三條溝通路徑，五十個人 1225 條。大公司之所以沒被平方級壓垮，是因為做了大量壓縮：設計師考慮 100 種方案，最後只出一張圖或三頁 PPT，壓縮到人類帶寬能處理的水平再交給下一個人，下一個人再重建，中間產生大量幻覺和誤解。整個公司對不起，不是有人故意歪曲，而是傳播帶寬本身就是有損壓縮。

29:10

波音 777 之前，圖紙要打印出來傳

波音早期用手畫圖，後來用 CAD，但一個部門畫完圖會打印出來交給下一個部門，下一個部門用肉眼看圖再畫自己部門的圖拼起來——因為兩個 CAD 文件不通，中間靠人類做橋梁。一張門可能要反反覆覆修改一萬兩千多次，最後還要用實體木頭假飛機做模擬。直到波音 777 才在雲端搞一架雲飛機，大家在數字空間看門和門框對不對得上、五個地方能不能用同一個螺絲。作者說，今天的會議紀要就是那張打印出來的圖紙：關於一個智能耳機開了 12 個會，紀要是單獨的而不是連續的，兩個會結論衝突要靠人腦發現。

39:10

出門問問不準人跟人開會

出門問問每個項目有一個自己的 agent，管理項目全部上下文、進展、代辦、風險，每個人每天跟這個 agent 溝通。李志飛比較激進，有個說法是不準人跟人開會，信息不該從一個人流轉到另一個人。安克創新的做法是每個項目一個 ID，項目 agent 把信息全部彙總，流程從 20 個環節變成三四個大環節由 AI 總控，交接從 20 次變成 4 次，每次 agent to agent 交接傳遞明確的核心數據對象。Claude Tag 則是持續讀授權給它的所有上下文，主動參與對話，比如隔壁部門已經把螺絲改了，這邊討論換供應商時它會冒出來說不能換。

52:10

又要過程又要結果，只有 AI 會答應

K12 教育公司的朋友找 AI 電銷工具，作者推薦了按效果付費的人工電銷頭部公司，對方說還是想找 AI。原因是內部外呼團隊只要定下 KPI 總有辦法拉到，但過程話術永遠不是想要的——不能提打折、不能不合規、不能引誘太過分，又要 KPI 壓力。這種自相矛盾的要求只有 AI 會答應，人類提的話就會想把老闆幹掉。安克楊萌認為檢查點優於行動、先於行動，標準貼在檢查點裡，檢查 agent 上下文要獨立；徐文浩分享過 agent 做測試用例會把用例全 mark 掉假裝跑一遍全是綠燈，所以要搞對抗性的乾淨 agent。

1:05:20

是 agent 推動流程，不是人用 agent

安克早期做了很多 agent 培訓，滿意度巨高，回去大家都不用，因為本質還是人在使用 agent，整個活的流程還是人在推進，人催人、每個人催自己的 AI，人是發動機，agent 可有可無。後來他們提出：是 agent 去推動流程，而不是人去用 agent。把 agent 提到組織協調和推進這一層，前後兩種做法節點看起來差不多，實際上差很多——不光節點減少，節點和節點之間的流轉也交給 agent 完成，人被 agent 叫過來。

1:06:10

工作自己發現自己，自己舉手

發現工作是一切的起點，最高境界是工作自己發現自己、自己舉手說應該被幹了。海底撈門店攝像頭監控所有臺子，平板告訴哪張桌子需要清理、哪張剛走、哪張已準備好，機器馬上識別馬上派活。美的以前每兩個小時班組會跑到大屏前碰一下，現在用人形機器人去掃、去發現問題、自己派工單。安克在亞馬遜上某產品銷量猛跌，系統自動發現警報，自動分析是不是沒庫存、廣告流量減少、有差評，把數據打包彙總生成工作項目，派給最能解決的人，不用等週會上過數據。
