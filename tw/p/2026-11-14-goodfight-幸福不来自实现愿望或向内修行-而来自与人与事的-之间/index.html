得到你想要的東西並不會讓你更快樂

Haidt 說最初版本的書名設想是關於兩種幸福假說的對照：第一種是「幸福來自得到你想要的」，但這在心理學上很快被證偽——左前額皮層專門負責追逐、追蹤、達成目標的迴路，讓「追求過程」本身極度愉悅，可一旦真正達成，你得到的不是巨大的快樂，而只是「釋放」「如釋重負」的感覺，且很快習慣化。這是整期節目論證幸福觀的起點，也是他否定「成就至上」敘事的理由。

— Jonathan Haidt
6:40

幸福來自「之間」，不是來自外或內

Haidt 提出他自認為對幸福文獻的原創貢獻：幸福既不來自外部成就，也不完全來自斯多葛式的向內修煉，而是來自「之間」（between）——即在信任網絡中與他人的嵌入（愛）、與自己工作的深度投入（工作）、以及與某種超越自身之物的聯結（道德共同體）。三者都做到位，人就會處在自己基因允許範圍內的幸福上限。

— Jonathan Haidt
18:30

斯多葛比佛教更適合現代人

Haidt 承認自己原本以為佛教會是書中「心理學上最優」的傳統，但寫作過程中改變了看法：斯多葛允許你深愛配�removeal和子女、對他們產生依戀，只是要提前做練習準備好可能失去他們；而不是像某些佛教分支那樣要求對得失保持徹底的情感無差別。他甚至說如果自己二十歲的兒子選擇去打坐修平靜，他會「很失望」，因為他想讓兒子去經歷、去冒險、去心碎再愛。

— Jonathan Haidt
42:00

手機禁入校園是「一場速勝的海灣戰爭」

Haidt 把過去兩三年社交媒體立法的進展分成幾條戰線：手機禁入校園推進神速，他稱之為「沙漠風暴行動」，幾乎沒有真正的反對聲音，老師和學生都喜歡；延遲到16歲才能用社交媒體的戰線更難，但澳大利亞已經立法實施，歐盟也在跟進；而「不給孩子智能手機」這條線雖然沒有立法可能，但他認為社會觀念正在轉變，因為「iPad寶寶」表現出語言發育遲緩等明顯的神經發育問題。

— Jonathan Haidt
58:00

年齡驗證不等於身份驗證，但英國的做法走偏了

Mounk 質疑限制16歲以下使用社交媒體會把未成年人隔絕在互聯網大片內容之外，還可能迫使用戶向政府交出身份信息。Haidt 反駁說澳大利亞的法律不限制內容訪問（孩子仍能在YouTube上搜到任何東西），且法律明確規定平臺不能僅靠政府ID來做年齡核驗，蘋果和谷歌已經可以做到只驗證年齡而不暴露身份。但當 Mounk 的製作人提供了她在英國因訪問 Substack 私信而被要求上傳身份證的親身經歷後，Haidt 承認英國的執行方式有問題，他明確反對基於內容的審查式監管，只支持純粹的年齡限制。

1:01:30

現狀已是「一代人的毀滅」，不作為不是選項

面對「證據尚不完全充分是否應該立法」的政策學難題，Haidt 不糾結於舉證標準之爭，而是直接把立場定在：PISA測試顯示全球閱讀能力下滑，現狀已經是對一代人心理健康和教育的摧毀性傷害，誰都不能說「維持現狀」是個選項，如果有人能想出比設定年齡限制更好的辦法來消除社交媒體的內在問題，他願意討論，但必須做出重大改變。

— Jonathan Haidt

術語

embeddedness嵌入性
指個體在與他人、工作、更大事物之間建立的深度聯結，是 Haidt 定義幸福「之間說」的核心概念
set point / set range幸福設定點/區間
心理學概念，指個體受基因影響而形成的幸福水平基準區間，並非固定不變的一個點

指經歷適度挫折或壓力反而變得更強韌的心理特質
