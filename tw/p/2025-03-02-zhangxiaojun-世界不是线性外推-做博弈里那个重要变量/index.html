世界不是線性外推：做博弈裡那個重要變量

如果世界是邏輯推導，今天最大的推薦引擎公司是百度。肖弘說創業者要做的不是推演必然，而是讓自己成為改變博弈結果的那個變量。

VC 的貴不體現在你差的時候

肖弘把資本定義為工具，而且是一種很貴的集資手段。他給出的機制是：VC 的貴不體現在你不好的時候——按條款美國正統的融資是不用還的——而體現在你好的時候，你牛逼了，付出的代價更大。由此推出他對競爭對手的判斷：那家公司融了更多錢，就必須向投資人交付更大的故事，於是被迫做錯的事。他的結論是，哪怕最後你的事情更小，也比做一個錯的事情好很多，CEO 應該有勇氣做正確而小的事。

— 肖弘
44:45

預判大廠：外掛一定會被幹掉

企業微信開放接口時，肖弘判斷外掛一定會被平臺治理掉，但沒人知道什麼時候。他的推理是：只想客戶，客戶當然希望發越多廣告越好；但想平臺，就知道微信生態不能亂，騰訊一定會限制。於是關鍵動作不是等外掛被幹掉再開發，而是打提前量——因為開發一個 SCRM 工具至少需要一個月，等到那天再動手就晚了。他總結成一條可複用的原則：面對一個你幾乎認為一定會發生、但不知道何時發生的事，在能承受的成本範圍內越早準備越好。

— 肖弘
1:11:08

Jasper 慶祝擴招時，他看到了裂縫

肖弘研究 GPT-3 API 上跑得最成功的公司 Jasper，看到創始人寫公開信慶祝公司從 9 人漲到 200 多人。他的判斷相反：管理本身是反規模的，人越多破事越多，這家公司的執行可能會變慢。第二個判斷是 Jasper 定價太貴，而按計算機產業的樸素認知，能力和 API 成本會大幅下降，所以應該會出現偏個人、professional 而非企業採購的市場。第三，ChatGPT 出來後他確認對話式才是大眾對 AI 的想像。三條加在一起，讓他在 ChatGPT 發布之前就決定立項 Monica，內部目標只是一個月賺 5 千人民幣。

— 肖弘
1:28:22

買來的增長會讓團隊學不到東西

收購 ChatGPT for Google 之後，肖弘沒有把它改名成 Monica，而是重新做一個產品。原因不是品牌，而是增長反饋：ChatGPT for Google 每天有自然流量帶來的幾萬新增，如果團隊守著它，某位同事找到每天帶來 200 新增的方法也不會覺得了不起，團隊的知識學習速度會變慢。重新做 Monica，大家自己找到一點點新增都會開心，從而學會怎麼在海外做增長和運營。同時買來的產品是資產，導量不會有損失，而投廣告是丟到水裡的錢，會讓人猶豫。

— 肖弘
2:14:52

新時代的安迪比爾定律

肖弘用半導體產業的安迪比爾定律解釋 AI：不管安迪造了什麼，比爾都會吃掉它。放到今天，模型能力一直在進化、越來越便宜，但殼也需要進化。Cursor 成立很早，真正為人所知是 Cloud 3.5 Sonnet 發布之後——模型能力提升帶來了它產品能力的迭代。如果沒有 Cursor，Cloud 3.5 Sonnet 在 Claude 裡也能寫代碼，但不會那麼流暢。所以模型能力外溢之後，需要第三方廠商把用戶可感知的價值呈現出來，這是創業者可以定義的部分。

— 肖弘
2:26:59

把思考過程放出來是體驗創新

肖弘認為 DeepSeek 全球爆火不只是技術強，而是把技術上的創新點以用戶可感知的方式展示了出來。他引用 Publicity CEO 的說法：AI 時代兩個巨大的體驗創新，一是聯網回答時標出引用來源，二是把 LM 思考的過程展示出來。OpenAI 的 o1 其實也有思考，但 o1 要收費、只展示簡化版，很多人根本不知道這回事，所以錯過了這個體驗創新。DeepSeek 免費、完整展示，加上模型質量確實拉到第一梯隊，老家朋友都能感受到代際差別。

— 肖弘
2:36:05

Agent 應該自己寫代碼調 API

肖弘描述被閃電擊中的瞬間：用 Windsurf 的 Yolo 模式時，Agent 說它要去 GitHub 上下代碼、搞一個事情再寫。他意識到它居然在用工具。由此推出 Agent 的架構：一個虛擬服務器、一個瀏覽器，能自己寫代碼調用 API。因為人類很多知識和服務不是通過 API 而是通過 web 調用的，所以必須帶瀏覽器；因為要執行命令行、裝庫，所以需要雲上的虛擬機，壞了無所謂，任務結束可以釋放。他還指出 Yolo 模式讓用戶填 yes 是甩鍋——小白用戶根本不知道 yes or no。

— 肖弘
3:12:32

用博弈思考，而不是邏輯推導

肖弘區分兩種思考方式：邏輯推導是「百度有最好的算法工程師，所以百度一定會把推薦做掉」；博弈思考是因為你的出現和其他 player 的出現，整個環境不一樣了。他舉例：如果沒有 DeepSeek 這一波，大家不會思考開源；如果最初做 ChatGPT 的是第三方公司，OpenAI 也許會選擇做純粹的 platform company 而不是 consumer app company。他前一次創業做企業微信 CRM 也是同理——因為生態裡有人做得很好，企業微信就說交給生態去做。所以創業者要儘量讓自己成為那個重要的變量。

— 肖弘
