一堂「證明音樂很主觀」的課失敗了

音樂心理學家 Lisa Margulis 在課堂上放一段學生沒聽過的瓦格納歌劇前奏曲，本想證明每個人的聯想都不同，結果第一個學生說「海盜」，第二年她改用紙條匿名收集答案，打開第一張還是「海盜」。這促使她花了十年時間設計實驗，證實對從未聽過的樂曲，陌生聽眾也會產生高度一致的具體聯想。

— Lisa Margulis
25:40

大腦在追蹤聲音與情境的統計關係，不只是追蹤下一個音

Margulis 認為以往的音樂認知研究只關注聽眾對「下一個音是什麼」的預測，但真正重要的是大腦同時在追蹤一種聲音模式在過去生活裡反覆出現時所對應的情境。這解釋了為什麼一段從未聽過、甚至風格完全陌生的音樂，也能瞬間喚起具體而一致的畫面——是統計學習，不是巧合。

— Lisa Margulis
34:25

中國侗寨實驗戳穿了「普世聯想」的假設

團隊特意跑到中國一個很少接觸西方媒體的侗族村寨重複實驗，發現當地人同樣能很快產生共享的聯想故事，證明聯想的「一致性」本身是普遍的認知現象。但具體內容卻因文化而異：同一段美國聽眾普遍聯想到「獨自在家被兇手跟蹤」的音樂，在侗寨聽眾耳中變成了「在戶外和朋友玩耍」。

— Lisa Margulis
36:42

音樂里也有「母語者」和「雙語者」之分

在芝加哥的實驗裡，只熟悉西方古典樂或只熟悉印度古典樂的「單一音樂」聽眾，對自己熟悉的風格記憶更好、情緒反應更強；而兩種都熟悉的「雙音樂」聽眾對兩種風格都有強記憶和強反應。更驚人的是，嬰兒本能分辨巴爾幹民樂那種罕見節拍，但在芝加哥環境下到12個月大就會失去這種能力——只需一週被動播放巴爾幹民樂就能找回，成年人單靠被動接觸卻做不到。

— Lisa Margulis
46:25

把同一首曲子播兩遍，多數人會說第二遍更好聽

Margulis 在課上給學生放兩段「不同演奏版本」，實際上是同一份錄音，讓學生投票哪個更好。多年來大多數學生都說第二遍更有表現力、動態更戲劇化。揭曉真相後，學生才意識到純粹的重複聆聽本身就會改變人對聲音的感知，這也是她用來論證「重聽音樂會深化體驗」的核心證據。

— Lisa Margulis
1:16:52

愛爾蘭給2000名藝術家發基本工資，結果更敬業也更健康

研究發現職業藝術家平均幸福感更高，但焦慮和抑鬱也更高，原因是藝術一旦變成謀生手段，就會被收入不穩定、職業可持續性等壓力纏繞，形成一種「被不穩定化的心態」。愛爾蘭試點給2000名職業藝術家發放基本收入、不用操心賺錢只管創作，結果不僅公眾參與度提升，藝術家心理健康也改善，這項計劃後來被定為永久政策，蘇格蘭也表示要跟進。

— Daisy Fancourt
1:24:13

手工藝是最容易進入「心流」的活動，不是冥想

一項讓受試者記錄兩週內兩萬兩千段體驗、涵蓋兩百多種活動的大型研究發現，最容易誘發心流狀態的活動是手工藝。這解釋了為什麼在癌症治療陪護住所裡，哪怕只是圍桌摺紙、畫畫、拼圖，也能讓陪護家屬暫時從「接下來會怎樣」的焦慮裡抽離出來。

— Daisy Fancourt
1:28:22

公園跑的成績變慢了，這是好事

過去十年裡 Park Run 這類群眾跑步賽事完成時間變慢，不是因為大家跑得更慢了，而是因為越來越多本不自認是「跑者」的人也開始參與。Fancourt 希望藝術也能複製這個邏輯：重點不是「你畫得好不好」，而是「你參與了沒有」，評價體系應該從作品質量轉向參與本身的健康收益。

— Daisy Fancourt
