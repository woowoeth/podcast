打垮 UNIX 的不是 Windows,而是 Intel 扶持的 Linux

UNIX 陣營靠專有硬件和操作系統把客戶鎖死多年，Intel 先用 Windows NT 撬開缺口，但真正要命的是免費、能看源碼、不怕被鎖死的 Linux。

1:04

Intel 想把 PC 的打法複製到服務器

Intel 在消費 PC 市場靠出貨量堆出了別人追不上的良率和成本優勢——量越大良率越高，成本越低，利潤又能反哺更好的製造工藝，把 AMD、Cyrix 遠遠甩開。Intel 相信這套邏輯在企業服務器市場一樣能跑通，於是把目光投向了被 Sun、IBM、HP 等廠商靠 RISC 芯片和各自 UNIX 變種把持、動輒幾十萬美元的高端市場。

5:15

Pentium Pro 讓 x86 第一次追上 RISC

1995 年底發布的 32 位 Pentium Pro 有 550 萬晶體管、主頻 150-200MHz,在某些整數測試里居然小幅超過了當時最快的 RISC 芯片，業界為之意外。雖然 MIPS R10000 很快追回來，但 Pentium Pro 重置了人們對「桌面架構」性能上限的認知，配合同年發布的 Windows NT 4.0,第一次讓 x86 服務器在價格遠低於 RISC 系統的情況下達到可比性能，1996 年 NT 4.0 銷量增長 85%,拿下 27% 市場份額。

8:19

NSP 事件暴露 Intel 對微軟的隱憂

表面合作之下，1995 年 Intel 想推「原生信號處理」標準，讓 CPU 直接處理音視頻以促使用戶換更快的芯片，微軟卻認為這是繞開 Windows 的「中間件」,公開表態不支持，比爾·蓋茨還專門給 Andy Grove 發郵件表達不滿。更讓 Intel 不安的是 Windows NT 從設計上就是跨平臺的，除了 x86 還能跑在 DEC Alpha、PowerPC、MIPS 上——如果 NT 真的一統市場，微軟完全可以把 x86 降格成眾多硬件架構裡普通的一個。

14:42

GPL 協議救了 Linux,沒重蹈 UNIX 分裂覆轍

Linus Torvalds 1991 年發布的 Linux 內核在 1992 年的 0.12 版本採用了 Richard Stallman 的 GPL 協議——任何人都能讀、改代碼，但對外發布修改版就必須同樣開源。這堵死了公司把代碼改改就當閉源競品賣的路子，避免了 Linux 重蹈當年三十多種 UNIX 變種互不兼容的覆轍，也讓像 IBM 這樣派幾百名員工貢獻代碼的公司確信自己的投入不會被截胡。Torvalds 後來說，選 GPL 是他做過最正確的決定。

22:08

Intel 從忽視到下場支持 Linux

1998 年初，Fermi 國家實驗室等機構開始找 Intel,要求把數學庫移植到 Linux 上，Intel 一查 OEM 廠商的數據才發現近 20% 的公開 Web 服務器已經在跑 Linux——在桌面端幾乎零存在感的系統，服務器端滲透率高得出人意料。Andy Grove 得知後措辭激烈地要求採取行動。Intel 高管去見 Red Hat 時一度困惑：Red Hat 不擁有核心產品的知識產權，誰都能免費拿到代碼，這怎麼賺錢？CEO Robert Young 用番茄醬打比方說服了他們。

27:12

Intel 投資 Red Hat,微軟「炸了」

1998 年 9 月 Intel 聯合網景、風投 Benchmark 和 Greylock 投資 Red Hat,承諾技術支持並派駐工程師聯絡 Linux 社區。消息一齣，據 Red Hat 高管回憶微軟「炸了」,那個週末 Intel 高管接到好幾通微軟的憤怒電話。但此時微軟正因 1998 年 5 月被美國政府起訴壟斷而投鼠忌器，只能剋制。另一個被低估的連鎖反應是：Benchmark 一位合夥人正好是戴爾董事，牽線讓戴爾 1999 年初成為第一家預裝 Linux 的大廠。

35:29

Linux 2.4 補上多處理器短板，經濟賬算過來了

1999 年的 Mindcraft 測試暴露了 Linux 2.2 超過兩顆 CPU 就跑不動的硬傷，而 Windows NT 早就支持 4 路、8 路甚至更多處理器。2001 年的 Linux 2.4 解決了自旋鎖等問題，讓 Linux 能較有效地用到 16 甚至 32 顆處理器，打開了 Linux 進軍中端市場的路：一臺配四顆 Xeon、跑 Red Hat Linux 的戴爾服務器只要 2.4 萬美元，是同性能 Sun Fire UNIX 機器價格的一半。2002 年 Linux 服務器硬件收入增長 63%,UNIX 硬件收入反而下跌 11%。

40:44

Active Directory 才是微軟真正的護城河

面對 Linux 免費的攻勢，微軟真正管用的招數不是「Get the Facts」營銷戰，而是隨 Windows 2000 推出的 Active Directory——它統一管理一個組織里所有用戶和設備的身份認證與權限，把換 Windows 的成本從「換個操作系統」抬高到「重建整個組織的身份體系」。結果 2005 年 Windows 服務器收入首次追平 UNIX,2006 年反超。但 Linux 的增長大頭並不是從 Windows 那裡搶來的，而是持續蠶食 UNIX,並在超算、Web 以及後來的雲計算這些 Windows 從未站穩的新市場裡野蠻生長。
