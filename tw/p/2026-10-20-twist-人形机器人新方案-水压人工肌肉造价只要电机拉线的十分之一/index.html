Clone Robotics 不用電機拉線去模擬肌肉，而是給編織套管裡的彈性管加壓液體讓它直接收縮，CEO稱這套方案造價只要電機驅動人形機器人的十分之一。

Anthropic 把5%股權押給公益基金

Anthropic 宣布將5%股權投入一個公共利益基金，按節目援引的 CNBC 數據，這部分在2萬億估值下價值約1000億美元；董事會還有權在公司估值每比某個未公開基準上漲50%時，再追加2%股權。Elon Musk 當場在 X 上回應，說與其放進基金，不如直接把股份發給普通人，並宣布明年起每年給美國每個孩子一股 SpaceX 股票，作為一系列類似計劃的開端。

直接發股票，而不是靠慈善基金會

Jason 在4月的一段舊片段裡提出，美國人對AI的敵意很大程度上來自自己沒有分到好處——擁有風投基金、401k 裡有英偉達或谷歌股票的人對經濟感覺很好，沒有股票的人卻覺得自己被甩在後面。他認為與其把錢投進拿走大部分管理費的傳統慈善基金會，不如直接把 SpaceX 這類公司的股份發給普通人，這樣才能真正改變大家對AI的整體觀感。

— Jason Calacanis

公益股權基金也可能變成暗箱基金

Jason 對 Anthropic 這筆公益基金本身表示懷疑：錢進了賬戶之後，是由 Anthropic 管理層自己決定怎麼花，而不是直接分給公眾，這就留出了大量運作空間——可能變成照顧自己人的資金池，也可能在分配時製造新的群體對立。他的結論是，這筆錢帶著很多管理層自己的影子，很可能變成一個暗箱基金，這也是他更傾向於直接發股票方案的原因。

— Jason Calacanis
43:58

機器人肌肉不是拉線，是真的液壓收縮

Clone Robotics 的技術路線與 Tesla Optimus、Figure、Boston Dynamics 完全不同。後者都是用電機拉動肌腱去模擬肌肉效果，本質是滑輪加繩索。Clone 發明的水壓肌腱單元，是把一根被編織套管包裹的彈性管充入液體加壓，套管的編織角度限制了它向外膨脹，只能沿長度方向收縮，從而直接產生類似真實骨骼肌收縮的拉力，而不是用馬達去模仿這個效果。

— Dinoosh Radhakrishnan
56:20

液壓路線號稱成本只要電機方案十分之一

Dinoosh 把液壓肌肉技術的最大賣點歸結為供應鏈：電機驅動的人形機器人依賴大量定製齒輪，這些齒輪本身昂貴，而且各家都在搶同一批供應商，是行業瓶頸。Clone 的方案裡沒有一個齒輪，據他說在沒有規模效應之前，造價就已經只是電機驅動人形機器人的十分之一。他認為這才是風險投資人最終會在意的核心優勢，而不是仿真度本身。

— Dinoosh Radhakrishnan
58:20

機器人公司押注大模型會免費變強

Clone 過去五年幾乎把錢全砸在硬件和人工肌肉這個別人都沒在做的難題上，智能部分則是一個明確的賭注：Dinoosh 認為前沿模型會以六到十二個月的半衰期不斷被更便宜地復刻或開源，他舉了英偉達 GEAR 項目的例子。等有了真實機器人數據之後，只要有資本，就能拿最新的開源模型做強化學習後訓練持續追上前沿水平，不需要自己從零訓練大模型。

— Dinoosh Radhakrishnan
1:03:30

企業版先落地，家用管家還要等

Dinoosh 給出了明確時間表：2027年第一季度前後先部署能雙手協作使用電鑽、錘子這類工具的企業版機器人軀幹，用於裝配線等固定場景，他認為這部分能帶來數十億到上百億美元的營收；面向家庭的完整家用機器人管家，他估計還要再等兩三年。對於售價，他認同2.5萬美元是一個合理的目標價，同時表示未來也會做百萬美元級的奢侈品版本。

— Dinoosh Radhakrishnan
