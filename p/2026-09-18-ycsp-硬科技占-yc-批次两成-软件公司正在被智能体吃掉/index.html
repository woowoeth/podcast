硬科技占 YC 批次两成：软件公司正在被智能体吃掉

硬科技从 8% 涨到 20%

Diana 分析了最近 18 到 12 个月 YC 录取的公司，硬科技占比从 8% 涨到 20%。拆开看：机器人从 1% 到 6-7%，工业制造从 4% 到 10%，国防从 1.5% 到 5%，半导体和光子学从 1% 到接近 4%，电力基础设施从 1% 到接近 3%。这些数字在物理原子栈上普遍翻了三到五倍。同期，中位 YC 公司被录取时收入为零，过去批次结束时中位月收入约 8K，现在到 20K。

— Diana
3:04

技术创始人比例在上升

Jared 提到当前夏季批次里，每六个创始人就有一个有 PhD，远高于历史水平。原因是做硅光子这类方向，通常需要很强的研究背景。Gary 补充说，过去硬科技难是因为供应链和软件工程是限制因素，现在有了 codegen，顶级全栈硬件不再需要招一千个优秀工程师，一两个或一个小团队就够，这改变了经济学。真正的看多逻辑不是投资人回避软件，而是模型本身在加速科研，让初创公司更早做出研究突破。

— Jared
5:05

国防和太空成了新叙事

Gary 说有三个宏观趋势在推动原子增长。一是 SpaceX 成功 IPO 后，一代创始人想造太空公司，比如 Exosat 做主权 Starlink 方案，Beyond Reach Labs 做卫星太阳能板。二是这代创始人成长于战争被高度讨论的环境，想做国防。Icarus 做太阳能 U2 侦察机，能做监视和通信，已拿到新战争部的七位数合同；Nine Mothers 做反无人机防御，是带 CV 的霰弹枪炮塔，特种部队在采购。三是算力本身是重物理过程，A100 每小时成本在涨，因为需求太大供给不足。

— Gary
8:08

硬件公司跑出软件增速

Nox Metals 把金属制造搬回美国，在底特律的空工厂里重建金属供应链。它的客户是新兴国防科技公司，需要金属造东西，而现有供应商多是反应慢的老生意，跟不上新国防公司的节奏。Gary 类比 Web 2.0 早期：新初创公司更愿意从新初创公司买东西，因为能同速协作，就像用 Stripe 而不是传统信用卡供应商。PG 发推说 Nox Metals 在以软件增速增长。

— Gary
10:12

算力栈从芯片挖到电力

Diana 说 GPU 价格反常：A100 已经算老，但每小时成本还在涨，因为需求超过供给。围绕数据中心上线，从选址建设、软件、实际 buildout 到供电方案，都有初创公司在做。往下走到核心计算硅：Lamb Labs 做新处理器，Bot 做用三进制表示的新定制硬件架构，因为 Nvidia 从 A100 到 H100 再到 B300，浮点精度一代代下降，而 LLM 架构不需要全精度浮点，FP2 甚至也能用。Dipole Labs 做全光交换机，因为电子交换机速度跟不上 GPU，成了很多数据中心的瓶颈。

— Diana
17:16

系统记录公司要么被吃要么变 harness

Gary 提出：如果你是系统记录公司，要么被掠夺——放出 MCP 后数据护城河消失，切换变得很容易；要么自己变成 harness，成为人们不只是读写、而是在里面完成工作的场所。他举 RKGI 基准为例，同一个模型插进不同 harness 表现不同，模型加 harness 才等于输出。有人声称 Astra 配自定义 harness 在 RKGI 3 上超过 90%，而几个月前这个数字还在低两位数。

— Gary
18:19

做完整任务的软件占比翻倍

Diana 说 YC 录取公司里做全栈端到端任务的比例从 10% 涨到超过 25%。区别在于智能体真的把活干了，而不是像五到八年前的 SaaS 那样只是点解决方案、还需要人来操作。增长最快的正是这些做完整工作流的公司，比如保险经纪、临床 intake、医疗账单。Jared 补充，距离 agentic coding 真正可用（Opus 4.5）快一年了，这些工作流开始全面开花，人们愿意为「把活干完」的软件付更多钱。

— Diana
21:19

三个月从零做到七位数收入

Diana 说今年第一次见到公司在批次期间从零做到七位数收入，跨度只有三个月，过去这需要 18 个月或更久。部分原因是他们在解决真问题，加上 agentic coding 让产品成熟度更高，创始人可以同时跑 20 个编码智能体会话。另一个快速增长的类别是向实验室卖数据或 RL 环境，很多公司很低调。YC 过去两年投了超过十几家年收入超 1000 万美元卖数据或 RL 环境的公司，很多达到数亿美元，公司才成立几年。

— Diana

术语

harness执行框架
包裹模型、让它能实际执行任务的软件层，模型加 harness 才等于输出。
RL environments强化学习环境
给模型做强化学习训练用的模拟或真实交互环境，是实验室花钱买的数据品类。
codegen代码生成
