2:03

资本寒冬其实没过去

王梦秋从两个角度看：钱的角度，今年愿意出手的钱比前两年多，但增量主要来自原本观望的机构，相对国资体量不算大；可投项目的角度，一级市场并没有比过去两年更繁荣，还是 AI、硬科技、低空经济那几个领域，消费依然很不活跃，没人愿意烧钱做消费，大家更感兴趣的是已经盈利、规模到一定程度的公司。所以如果两年前叫寒冬，现在也并没有完全走出来。

— 王梦秋
4:04

DeepSeek 没繁荣应用生态

王梦秋认为 AI 应用创业的核心问题不在底层大模型够不够便宜，而在应用还没找到真正让人兴奋的场景，这不是 DeepSeek 能解决的。DeepSeek 开源相当于信息平权，抹平了大公司和小公司在使用上的可能差异，但大家原来最大的问题也是算力，DeepSeek 不也要好算力吗？所以本质上它并没有繁荣应用生态。过去两年国内没出现特别好的应用，是因为大家还没找到好的应用场景。

— 王梦秋
5:05

AI 没创造新场景新需求

王梦秋说，大家都觉得这一代 AI 是技术革命，但它现在能满足和实现的东西，并没有创造新的场景和新的需求。以 Agent 为例，从 2023 年业界就开始搞，最早有 auto GPT 的概念，过去两年中美都在探索，但一直没起来。哪怕是最垂直的旅行规划 Agent，中美都有不少公司在做，想自动做行程规划并完成酒店机票 booking，但真正使用时跟人类做出来的区别还是挺大的——人在过程中会不断修正需求，一开始想住哪，一搜发现太贵就换地方甚至换目的地。所以 AI 在满足已有需求上，很多领域并没有达成体验飞跃，更没到创造新需求。

— 王梦秋
9:06

需求分析比 AI 技术更重要

王梦秋认为最重要的事情不是 AI 技术本身，而是需求分析：到底什么需求在当下满足得不好，可以通过这一代 AI 技术达成体验上的飞跃。它不能只是一个 minor 的改进，minor 的改进不足以支撑一个真正独立的 business，一定得是体验上的飞跃——替我节约大量时间、给到我让我惊喜的结果。就像 AI talking bot 一开始让人惊喜，DeepSeek 也是先不说性能或省算力，它给出来的答案距离准确还挺遥远、幻觉非常严重，但它给到你的 talking 方式会让你觉得比之前的 bot 更像人，尤其对中国人来讲更愿意跟它说话。

— 王梦秋
11:07

拿 DeepSeek 当神婆

王梦秋说自己拿 DeepSeek 当神婆，需要情绪价值或对什么事不确定时就去问它，它说的东西你知道它在胡说八道，但它会让你很舒服。她推测这是因为后训练阶段用了强化学习，你给它的 feedback 越多它就越学习，比如你读答案读得仔细、读得时间长，它可能认为这是好的反馈，或者你直接说「你说的对」「你胡说八道」。她认为有些元宝也非常有情绪价值，但用多了会觉得它太顺着你、太知道你想要什么，就有点舔狗。

— 王梦秋
15:09

微信元宝的预期是个人

王梦秋用微信元宝做人的背景调查，问它认不认识某公司某人、怎么评价，初衷是希望它抓出散布在各种论坛、小红书里关于这个人的信息。她承认这个需求不合理，但 for some reason 觉得它是一个人，就可以对它有这个需求。结果啥也没找着，她认为这可以解释：大量论坛不让 AI Bot 抓取，Bot 遵守协议也不应该抓取，抓来的内容是否用于训练也要考虑真实性问题。但她从用户接触层面觉得远低于预期，并由此思考：元宝呈现为微信好友时，用户希望它满足的事情，和元宝作为 APP 时应该不一样。

— 王梦秋
25:11

通用 Agent 可能是伪命题

王梦秋说腾讯现在并没有一定要做通用 Agent，她甚至认为通用 Agent 可能是个伪命题，是不是真的分通用和垂直也未必。清流从去年到今年一直在看 Agent 创业，有做通用的，也有把某一种工作流比如视频剪辑转化成 Agent 来满足的，后者挺刚需。她觉得这有点像当年大模型和上层应用的区别，有些团队想搭的是 Agent 框架，让更多应用层和工作流的 Agent 化基于框架再做，这一层像当年的大模型作为 foundation。她一直觉得通用 Agent 是不是成立要打一个大问号，至少目前市场上没有什么通用 Agent 或做得好的。

— 王梦秋
35:22

小组织利好年轻创业者

王梦秋说，也许 00 后创业在现在这个 moment 会比过去看 90 后创业成功概率相对高一些，因为现在的组织倾向于小组织。原来觉得太年轻的人做创始人最大的问题是管理能力和人生阅历，做成一个 business 除了好产品想法、好技术能力，更大的是对组织的管理能力和对整个 industry 的判断，这需要人生阅历。但上一代 mobile network 时代，最后要管理的人数不少、复杂度在那；这一代 AI 应用层有可能小组织能做成大生意，所以 00 后没有那么多人生阅历也有一定概率做成。但她强调不必追着投 00 后，以年龄划分 founder 是非常 reductive 的事。

— 王梦秋
38:18

具身智能最缺仿真器

王梦秋说清流投了具身智能，投了陈建宇的星动纪元，最近还会想办法投一个做仿真器的公司。因为对具身智能来讲，最仿定门头的问题是在现实世界没有那么多数据，必须在虚拟环境中模拟得足够好，再把算法迁移到现实世界，还要想办法弥补 sim2real 的 gap，所以仿真器是具身智能产业的基础设施，但这件事非常非常难做。清流沿着星动纪元想找产业链上的机会，就像当年投新能源车沿着主机厂发现产业链机会，但现在还有点早，因为大家都还没进入量产阶段，供应链上的机会目前还没看到。

— 王梦秋
44:23

眼镜替代手机不自然

王梦秋自己买了 Meta 的 Ray-Ban 眼镜，出门旅游时玩，愿意戴的原因一是比较好看、时尚，二是看着跟普通眼镜没区别，她不喜欢看起来与众不同的设备，VR 头显就是不可持续、不可日常穿戴、违反人性的。它兼具墨镜和耳机功能，有骨传导耳机，她很不喜欢耳机塞在耳朵里。但她也不会经常戴，因为本身不近视。她认为现在做 AI 眼镜的人还是很低刻的，核心是想明白解决什么问题、人什么时候需要戴这个东西。她不相信眼镜能替代手机，因为不自然、随时长在脸上不舒服，手机拿着沉放下就完了。

— 王梦秋
58:31

旅行是向内寻找

王梦秋去年差不多每个月都出去玩，去了沙特、德国、冰岛、日本。她说去沙特的感觉是这个国家在非常积极地拥抱现代化，非常年轻、欣欣向荣，当地 Tour Guide 完全不靠这个挣钱，甚至自己掏腰包请喝咖啡吃雪糕。德国是已经非常 well done 的国家，去德国是寻求心灵 peace。冰岛是极夜时去的，每天只有三四个小时天光，非常的世界末世感。她说现在出去玩跟 20 多岁不一样，首先比 20 多岁有钱，其次不再恨不得一天去十来个地方，更多是向内寻找，是外部变化的环境对内心的投射。

— 王梦秋
1:07:35

伟大不能被规划

王梦秋读了黄仁勋传、奥特曼传记、马斯克传记，给内部做了个 PPT，标题叫「伟大不能够被规划」——真正做出这么伟大的企业，其实你是无法提前预知和规划的，但是可以被学习。她试图总结三人有没有共性，最后发现没有太多共性，但黄仁勋跟马斯克有一个人性上的共性：他们没有试图做好人，在日常生活中、尤其在跟团队工作过程中不是那么好相处的人。她的结论是，你要想成为一个伟大企业家，可能就不要试图做好人，一定要有很 harsh 的局面、很 harsh 的关系，然后你要 behave harsh。

— 王梦秋
1:12:41

电影要先回答为什么去影院

王梦秋说现在观影人群为什么要去看电影，寻求情绪价值的方式太多了，看电影是一个门槛极高的活动。以前大家看电影是因为没有更多方式，现在刷短剧、刷短视频成本极低、更舒适，谈恋爱可以找咖啡馆坐着面对面刷短剧。以前觉得进电影院是社交方式，其实坐在黑暗中看电影谁跟谁说话，没什么可社交的。所以电影行业首先要回答一个问题：为什么大家还要去电影院看电影。她认为很多从业人员尤其是制作方没有意识到这个问题，没有想过要回答观众为什么要去看电影、想看什么类型、target 什么人群。

— 王梦秋
1:16:43

好东西顺应女性主义叙事

王梦秋认为《好东西》如此成功是顺应了当下的女性主义叙事，它是一个纯女性主义叙事，跟上一部姐妹片《爱情神话》还不一样，爱情神话更多是给你 double 了上海精致中产生活的各种可能性，最后讲了一个爱情的神话。她听说《好东西》在下层城市的票房不错，这是一个非常好的破圈，因为之前爱情神话更多在一线城市，而《好东西》让二三线城市的女性看到原来一线城市的女性可以这样生活。她喜欢这部电影、看了两遍，但觉得有些台词有点过于口号了，另外把里面所有男性都塑造得非常弱，她身边也有很好的、很强的男性。

— 王梦秋

讨厌三八妇女节

王梦秋说自己一直很讨厌三八妇女节，原因是「我觉得这件事情其实是因为你还太弱，所以人家专门要为你笑一个节日」，所以她从来不过这个节，特别讨厌这个节日，还把女生节和妇女节分开了，清华有个三七女神节。她说自己从成长经历中没有遇到过特别对女性不公平的事，不管是求学、在百度工作还是做投资，没有遇到过歧视、俯视或爹味。她认为整体上应该是平权，男性女性都作为独立的人来看，行为是不是合情合理就好，不要因为是女性就要求、每件事都上纲上线，这反而不是真正的平等。
