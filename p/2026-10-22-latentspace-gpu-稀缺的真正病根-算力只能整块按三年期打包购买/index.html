一个客户撑起早期九成收入

Modal 真正的拐点出现在 2022 年 11 月到 2023 年 1 月：月收入从 100 美元跳到 2000 美元，再跳到 3 万美元。但这波增长几乎全靠一家客户——纽约的 Stable Diffusion 公司 Mage，在 2023 年第一季度一度占到公司收入的八到九成。Erik 说那一刻感受到的不是庆祝，而是「这下终于可以把焦虑放下」的松一口气。

— Erik Bernhardsson
13:48

算力市场从现货变成三年定金

Modal 早期几乎全靠从 AWS、GCP、Azure 买 spot 和按需算力，哪里便宜去哪里。但过去一年市场彻底变了：现在要拿到算力，得和将近 25 家云厂商签三年以上的合约，还要先付一大笔钱。公司为此新建了专职「产能采购台」，四个人天天打电话和云厂商谈判、验货，另外还有十人规模的工程团队专门处理裸金属服务器、网线、坏盘这些脏活累活。

— Erik Bernhardsson
19:25

他更怕暴跌，不怕涨价

很多人以为算力公司最怕 GPU 涨价，Erik 说恰恰相反：涨价对 Modal 反而是好事，因为公司已经锁定了大量三年期低价合约，相当于变相「做多」了 GPU 价格；真正让他担心的是价格突然崩盘，那会让所有在高点囤下长期合约的人严重亏钱。他也明确表态不打算去囤下整个市场，哪怕理论上现在就能这么做。

— Erik Bernhardsson
28:35

Neocloud 靠先签约再买卡滚雪球

他拆解了 nScale 这类新兴云厂商如何从几乎没有产能做到几千亿美元订单储备：先找 Anthropic、OpenAI 这样的大买家签下五年算力合同，拿着合同去华尔街融资，再用这笔钱向 Supermicro、Dell、英伟达采购硬件交付——本质是把还没买的卡预先卖出去。Modal 走的是产品驱动增长、客户分散的路线，很难用同样的杠杆玩法快速扩张产能。

— Erik Bernhardsson
34:27

Sandbox 从差点关停到占三分之一收入

Modal Sandboxes 是 2023 年一次午饭闲聊想出来的点子——「LLM 都在吐代码了，总得有个地方跑吧」，一两天就写出原型上线，但很长时间几乎没人用，团队一度讨论过要不要关掉这个产品。转折发生在同年下半年：模型突然擅长生成完整应用，Lovable 这类 vibe coding 公司、Ramp 的后台 agent、以及做强化学习的新实验室先后涌入，如今 Sandbox 已经占到 Modal 收入的三分之一。

— Erik Bernhardsson
44:13

沙箱该秒开秒关而不是云上开发机

他认为现在大部分人把沙箱当成「把开发机搬到云上」用，这是错的心智模型。真正该有的样子是：agent 24 小时在跑，需要执行命令时在百毫秒内拉起一个沙箱，跑完立刻快照、关闭。Modal 上沙箱的中位生存时间已经只有 8 秒。这能让 CI 测试真正做到「每个测试一个独立沙箱」并发跑，而不是现在这种每个分片都要重新装一遍依赖的笨办法。

— Erik Bernhardsson
47:34

Hugging Face 事件：被黑的是应用不是平台

攻破 Hugging Face 的 agent，利用的是部署在 Modal 上某个应用自身的漏洞，再借此拿到更大权限，并非 Modal 平台被黑——他用「AWS 上有人的应用被黑，不等于 AWS 被黑」来类比。事后团队在反思能否把安全默认设置收紧一点，参考 AWS 后来把 S3 公开桶默认收紧的做法，同时已经开始用 agent 专门尝试「越狱」自家沙箱找漏洞，目前还没找到。

— Erik Bernhardsson
1:18:56

矩形算力才是稀缺的真正病根

Erik 念出了自己之前发的一条推文：GPU 短缺最大的问题不是买不到卡，而是几乎所有产能都被打包成「三到六个月后才交付的三年期矩形」出售，这和大多数用户真实的、一天内忽高忽低的需求形状完全对不上。他认为 Modal 的核心价值正是靠聚合几千个客户的需求，把这些参差不齐的波动摊平成一条平滑曲线，再反过来把算力切得很细地租给每个人。

— Erik Bernhardsson
