打垮 UNIX 的不是 Windows,而是 Intel 扶持的 Linux

UNIX 阵营靠专有硬件和操作系统把客户锁死多年，Intel 先用 Windows NT 撬开缺口，但真正要命的是免费、能看源码、不怕被锁死的 Linux。

核心论点 · 点时间戳可跳到原声

1:04

Intel 想把 PC 的打法复制到服务器

Intel 在消费 PC 市场靠出货量堆出了别人追不上的良率和成本优势——量越大良率越高，成本越低，利润又能反哺更好的制造工艺，把 AMD、Cyrix 远远甩开。Intel 相信这套逻辑在企业服务器市场一样能跑通，于是把目光投向了被 Sun、IBM、HP 等厂商靠 RISC 芯片和各自 UNIX 变种把持、动辄几十万美元的高端市场。

5:15

Pentium Pro 让 x86 第一次追上 RISC

1995 年底发布的 32 位 Pentium Pro 有 550 万晶体管、主频 150-200MHz,在某些整数测试里居然小幅超过了当时最快的 RISC 芯片，业界为之意外。虽然 MIPS R10000 很快追回来，但 Pentium Pro 重置了人们对「桌面架构」性能上限的认知，配合同年发布的 Windows NT 4.0,第一次让 x86 服务器在价格远低于 RISC 系统的情况下达到可比性能，1996 年 NT 4.0 销量增长 85%,拿下 27% 市场份额。

8:19

NSP 事件暴露 Intel 对微软的隐忧

表面合作之下，1995 年 Intel 想推「原生信号处理」标准，让 CPU 直接处理音视频以促使用户换更快的芯片，微软却认为这是绕开 Windows 的「中间件」,公开表态不支持，比尔·盖茨还专门给 Andy Grove 发邮件表达不满。更让 Intel 不安的是 Windows NT 从设计上就是跨平台的，除了 x86 还能跑在 DEC Alpha、PowerPC、MIPS 上——如果 NT 真的一统市场，微软完全可以把 x86 降格成众多硬件架构里普通的一个。

14:42

GPL 协议救了 Linux,没重蹈 UNIX 分裂覆辙

Linus Torvalds 1991 年发布的 Linux 内核在 1992 年的 0.12 版本采用了 Richard Stallman 的 GPL 协议——任何人都能读、改代码，但对外发布修改版就必须同样开源。这堵死了公司把代码改改就当闭源竞品卖的路子，避免了 Linux 重蹈当年三十多种 UNIX 变种互不兼容的覆辙，也让像 IBM 这样派几百名员工贡献代码的公司确信自己的投入不会被截胡。Torvalds 后来说，选 GPL 是他做过最正确的决定。

22:08

Intel 从忽视到下场支持 Linux

1998 年初，Fermi 国家实验室等机构开始找 Intel,要求把数学库移植到 Linux 上，Intel 一查 OEM 厂商的数据才发现近 20% 的公开 Web 服务器已经在跑 Linux——在桌面端几乎零存在感的系统，服务器端渗透率高得出人意料。Andy Grove 得知后措辞激烈地要求采取行动。Intel 高管去见 Red Hat 时一度困惑：Red Hat 不拥有核心产品的知识产权，谁都能免费拿到代码，这怎么赚钱？CEO Robert Young 用番茄酱打比方说服了他们。

27:12

Intel 投资 Red Hat,微软「炸了」

1998 年 9 月 Intel 联合网景、风投 Benchmark 和 Greylock 投资 Red Hat,承诺技术支持并派驻工程师联络 Linux 社区。消息一出，据 Red Hat 高管回忆微软「炸了」,那个周末 Intel 高管接到好几通微软的愤怒电话。但此时微软正因 1998 年 5 月被美国政府起诉垄断而投鼠忌器，只能克制。另一个被低估的连锁反应是：Benchmark 一位合伙人正好是戴尔董事，牵线让戴尔 1999 年初成为第一家预装 Linux 的大厂。

35:29

Linux 2.4 补上多处理器短板，经济账算过来了

1999 年的 Mindcraft 测试暴露了 Linux 2.2 超过两颗 CPU 就跑不动的硬伤，而 Windows NT 早就支持 4 路、8 路甚至更多处理器。2001 年的 Linux 2.4 解决了自旋锁等问题，让 Linux 能较有效地用到 16 甚至 32 颗处理器，打开了 Linux 进军中端市场的路：一台配四颗 Xeon、跑 Red Hat Linux 的戴尔服务器只要 2.4 万美元，是同性能 Sun Fire UNIX 机器价格的一半。2002 年 Linux 服务器硬件收入增长 63%,UNIX 硬件收入反而下跌 11%。

40:44

Active Directory 才是微软真正的护城河

面对 Linux 免费的攻势，微软真正管用的招数不是「Get the Facts」营销战，而是随 Windows 2000 推出的 Active Directory——它统一管理一个组织里所有用户和设备的身份认证与权限，把换 Windows 的成本从「换个操作系统」抬高到「重建整个组织的身份体系」。结果 2005 年 Windows 服务器收入首次追平 UNIX,2006 年反超。但 Linux 的增长大头并不是从 Windows 那里抢来的，而是持续蚕食 UNIX,并在超算、Web 以及后来的云计算这些 Windows 从未站稳的新市场里野蛮生长。
