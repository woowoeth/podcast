模型竞赛之外：人机接口才是编程产品的胜负手

Cursor 从第一天就认定：编码的未来是伪代码，竞争在人机接口而非模型；靠这个判断拒绝插件、推迟企业销售，在微软和 Anthropic 的夹缝中成为独立赢家。

AI编程Cursor创业决策企业销售并购投资判断
三位 a16z 投资人亲述 Cursor 从 A 轮到 D 轮的决策全程，讲透产品型公司如何在巨头夹击下靠克制的选择胜出。

核心论点 · 点时间戳可跳到原声

2:22

Copilot 称霸下的中间路线

2024 年初，AI 编程的共识是 GitHub Copilot 遥遥领先，微软同时拥有 VS Code、Office 和 OpenAI 权重。但当时 agents、long context、reasoning 都不存在。Cursor 没有站在「训练代码专用大模型」或「做插件」两个极端，而是选了中间道路：把人与模型的接口当作产品核心。这一选择在当时看似违反直觉，事后被验证为正确。

— Martin Casado
6:24

为什么不做代码专用模型

面对「为什么不训一个 coding-specific 模型」的质疑，Cursor 的答案是：你是用自然语言跟模型沟通的，所以模型必须理解人类经验和语言的广度；要做一个编程模型，本质上是在做一个前沿语言模型，这极其困难。这个推理贯穿了他们所有决策：如果真相信产品，就不会做插件，因为那就成了别人的产品的一部分；也不会过早进入企业销售，因为产品本身就是获客方式。

— Martin Casado
11:02

增长模型的假设被打破

从 A 轮到 B 轮只隔了一个夏天，增长投资者习惯的假设全部被打破：通常到 2500 万到 5000 万 ARR 时自自助获客会见顶，需要引入销售负责人；Michael 直盯着投资人眼睛说「self serve is not petering out」。David 一类增长投资人被迫扔掉「五年后增速衰减到 25%」的模型。这笔投资的关键不是看增长曲线，而是接受一家公司可以不按历史规律成长。

— Sarah Wang
17:41

Cloud Code 吓不到我们

Cloud Code 在 2025 年 5 月高调发布后，投资人问 Michael 怎么看。Michael 的回答是：我们在追逐全球最大的市场，竞争者一直存在，Copilot 是第一个，Cloud Code 只是轮转角色中的一个；大市场里永远有强敌，但这吓不到我们。这句话的震撼在于「谦卑与虚张声势的混合」——这是面对巨头时必须的获胜气质。

20:00

技术变革先于商业模式

2025 年夏天外界对 Cursor 的毛利议论纷纷，但业务其实一直很好。投资人常犯的错误是在技术变革尚未定型时，用传统商业模型的标准去拆解一家新公司。历史上每一波浪潮都是先有技术转型，才有商业模式；互联网早年也没有变现路径。真正稀缺的是无限需求和增长，毛利问题会被时间解决。

22:01

企业销售：从拒绝到最快组建

早期 Michael 拒绝做企业销售，甚至设置 enterprise@cursor.com 敷衍。但团队始终是「学生心态」：当他们发现大型实验室用补贴或免费的单层产品抢市场，而真正的大额支出和毛利在企业端，就立刻决定进入。决策之后执行力极快——这可能是有史以来搭建最快的销售团队。他们的逻辑不是「产品不够好才需要销售」，而是「产品是获客引擎，企业销售是生存结构」。

— Martin Casado
26:10

用考古法招顶级 AE

Cursor 把做产品的严谨应用到招聘：先研究哪 10 家公司在这类销售上做得最好，再定位这些公司里的顶尖团队，最后锁定那 1、2 个推动变革的明星 AE，通过一层层 back channel 确认。早期他们需要能承受不确定性的 founding AE，而不是只会跑标准流程的人。Jordan 和 Roman 把这个方法规模化，让销售团队快速扩张而不稀释文化。

— Sarah Wang
35:15

并购：先买团队后定战略

Cursor 的并购哲学分两阶段：早期是 talent via acquisition——在人才争夺战里直接买团队，不担心整合复杂度，因为文化足够强；到收购 Graphite 时才转向战略方向。他们对待并购像对待产品一样，有清晰计划并执行到位。收购创始人并融入公司文化的做法，Cursor 比 Anthropic 更早，而且不是把人塞进 IC 岗，而是真正用创始人方式建公司。
