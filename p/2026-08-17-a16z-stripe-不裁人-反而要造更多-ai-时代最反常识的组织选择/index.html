Stripe 不裁人，反而要造更多：AI 时代最反常识的组织选择

当所有公司用 AI 优化成本结构时，Stripe 选择把省下来的工程师产能全部投入新产品——因为优化成本是「做空自己的未来」，而造更多是「做多」。

Stripe 要把自己变成内部创始人的平台

Will Gabrick 说 Stripe 一直是对外服务创始人的平台，但现在要变成「内部创始人的平台」。逻辑是：当单个高级工程师能完成两年前两个团队的工作量时，组织不该缩减，而该让每个工程师都像创始人一样有自主权。Stripe 收购的 Metronome、Privy、Bridge、Lemon Squeezy 的创始人们现在都在 Stripe 内部领导重要业务线——Scott Woody 管 billing，Henry 管 crypto，Zach 管 OpenUSD 和 Bridge。这不是巧合，是刻意把创始人放进组织内部当「auteur」来用。

— Will Gabrick
13:54

Minions 一周生成 7000 个 PR，占全公司 30%

Stripe 内部工具 Minions 的核心设计是「one shot」：给一个 prompt，它直接构建、跑完 CI/CD 和全部测试，然后等人 review——没有迭代、没有 planning mode。今年 1、2 月博客发布时是每周 1200 个 PR，上周达到 7000 个，占 Stripe 当周全部 PR 的 30%。Will 说这就是「glorified RELF loop」，让 agent 极度强大。配套的组织变化是「flatter, smaller teams」：一个高级工程师现在可以同时 orchestrate 16 个 agent，Stripe Projects 的大部分 PR 就来自一个人。

— Will Gabrick
19:11

优化成本是做空自己，造更多是做多未来

David George 把两种 AI 策略总结为「long versus short」：优化成本结构是 short 自己的未来潜力，相当于资本配置里的「返还现金」；而 build more 是 long 未来潜力，相当于「再投资现金」。Will 用内部工具 Kai 举例：83% 周活、60% 日活，销售生产力提升 20%，但 Stripe 的反应不是「可以少招销售」，而是「payback 变好了，应该招更多销售」。他引用 Jevons paradox：资产变高效后，你要的不是更少，是更多。

— David George / Will Gabrick
25:23

AI 编程像注塑机：先做模具，再批量生产

Will 用注塑机（injection molding）比喻 agentic engineering：二战后消费品和玩具爆发，是因为 40 年代掌握了均匀熔化塑料并注入金属模具的螺杆技术。Stripe 现在做代码生产也一样——先创建 mold 和 templates，每个 repo 里放好 agent files，理解与金融机构集成的模式，然后把大量工作交给 agent，人类时间花在 code review 上，而 agent 做 code review 甚至比人更好。结果是 Stripe Tax 的全球 filing 功能只用了美国 filing 三分之一的时间，复杂度还更高。

— Will Gabrick
28:29

Agentic commerce 缺的不是模型，是原语

Will 说 agentic commerce 还没等到它的「Opus 4.5 Cambrian explosion moment」，因为没有大量重复出现的 canonical use cases。原因之一是 missing primitives：Stripe 和 Tempo 做了 machine payments protocol，服务方可以返回 402 响应告诉机器怎么付款。另一个开放问题是 checkout 该长什么样——browser automation 让 agent 爬表单是「skeuomorphic version」，原生版本还没出现。Will 认为 checkout page 最终会消失，对人类也一样。

— Will Gabrick
34:37

微交易过去不成立，是因为没有 agent 当消费者

微交易被讨论了几十年没成，Will 认为原因是：卖单篇文章永远被订阅模式和免费模式两头挤压。但 agent 改变了这个结构——你希望 agent 像蜂鸟一样在互联网上到处飞，这里 slurp 一点数据，那里做一点临时计算，人类不该为每个服务创建账号。同时稳定币让微交易第一次变得「eminently possible」：人类用稳定币要跳一堆坑，但给 agent 一个预算，它可以轻松把美元换成稳定币或使用 stored balance 完成结账，而且不介意来回折腾。

— Will Gabrick
37:39

稳定币是更好的全球支付平台，因为绕开了政治

Will 自称 infrastructure nerd，说稳定币就是比现有方案更好的移钱平台。印度 UPI 上低于 5 美元的支付占比约 86%，美国信用卡只有个位数百分比——好的廉价快速支付系统大多是国有化的。但全球经济需要一个「shelling point」，一个所有人都能同意的东西，而 crypto rails 正好解决这个政治问题：这个平台在哪里都能用。Stripe 用户可以用 fiat 在约 60 个国家使用，用稳定币可以在约 150 个国家使用。

— Will Gabrick
43:43

Token 正在变成钱的近似物，Stripe 要同时管好两种

Will 说他一直喜欢 token 这个词，因为它听起来就像钱的近似物，而且越来越是。Stripe 看到针对通用 token 消费者（Cursor、Replay 等平台用户）的攻击非常 sophisticated，和偷 Stripe 用户钱的攻击很像。所以 Stripe 认为自己有 mandate 在 token 上做和美元一样的事：安全、合规地移动、存储、发送。Will 把 token 使用分成两类——build things 的 OPEX 管理，和产品 efficacy 管理（怎么在不同模型间切换最有效），Stripe 想同时帮用户管好这两端。

— Will Gabrick
