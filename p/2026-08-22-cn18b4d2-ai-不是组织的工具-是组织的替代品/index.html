AI 不是组织的工具，是组织的替代品

单点提效带不来组织效率，因为真正的瓶颈是 60% 时间耗在对齐上；解法不是让人用 AI，而是让 AI 接管对齐、推进、闭环三件事。

0:01

提效了却没多赚钱的鬼故事

很多公司已经进入第二阶段：AI 学了也用了，个人提效明显，但整体效率没提高，或者效率提高了利润没增加，甚至裁员省了钱利润也没涨。作者把效率拆成三层：单点任务效率、组织协调效率、市场战略位置。大部分人只盯第一层，但公司要把个体努力协调成整体效果，第二层远比第一层重要；而哪怕组织协调做好了，打下来什么城市、站在什么生态位，才决定能不能赚钱。

4:30

飞机快 30 分钟，门到门只省半小时

阿姆达尔定律：一件事有很多环节，只优化其中一个，整体效果有限。上海到北京飞机 130 分钟，提速 30% 到 100 分钟是伟大科技进步，但端到端门到门要五个小时，省 30 分钟对五小时来说变化不大。更惨的是系统表现取决于最瓶颈的环节：洗菜切菜快十倍，灶台只有四个，整体可能只提升 1%；就算后厨全线提效十倍，门口人流量没增加，还是赚不到钱。

8:30

60% 白领时间花在对齐上

知识工作最大的消耗不是做事本身，而是开会、对齐、协调、对接、交接、等待。多份报告口径基本一致：60% 的白领工作时间在做协调性对齐性工作。作者建议翻自己上一周的日历，看多少时间在开会、多少会是为了沟通协调。工资越高的白领，这种对齐协调和人、信息、人情的交互就越多。火星探测器因为一家用英制、一家用公制，没对齐，飞了九个半月直接烧在大气层，一亿多美金打水漂——各自做的都对，整体是零。

18:56

AI 不是组织的工具，是替代品

作者提出暴论：AI 原生组织转型不是把原来的组织转一转更好地用 AI，而是想怎么用 AI 去替代原来组织的绝大部分功能。组织本身是近代发明，用来解决信息路由和管控机制两个问题。层级是因为一个人看不过来，但滴滴一个人能管上千司机；部门是因为人不是通才，但如果每个人旁边都有 AI 翻译，部门设计是否还需要；流程是因为看不到全局，但如果 AI 能看到全局，为什么还要人来控流程。就像坐月子不洗头，古人有道理，但热水器、电吹风、青霉素出现后，前提假设变了。

23:00

N 平方条路径，靠有损压缩硬扛

对齐分两件事：对齐事实（世界是什么样子）和对齐打法（我们要怎么做）。纯数学上 N 个人有 N 平方级对齐压力，三个人三条沟通路径，五十个人 1225 条。大公司之所以没被平方级压垮，是因为做了大量压缩：设计师考虑 100 种方案，最后只出一张图或三页 PPT，压缩到人类带宽能处理的水平再交给下一个人，下一个人再重建，中间产生大量幻觉和误解。整个公司对不起，不是有人故意歪曲，而是传播带宽本身就是有损压缩。

29:10

波音 777 之前，图纸要打印出来传

波音早期用手画图，后来用 CAD，但一个部门画完图会打印出来交给下一个部门，下一个部门用肉眼看图再画自己部门的图拼起来——因为两个 CAD 文件不通，中间靠人类做桥梁。一张门可能要反反复复修改一万两千多次，最后还要用实体木头假飞机做模拟。直到波音 777 才在云端搞一架云飞机，大家在数字空间看门和门框对不对得上、五个地方能不能用同一个螺丝。作者说，今天的会议纪要就是那张打印出来的图纸：关于一个智能耳机开了 12 个会，纪要是单独的而不是连续的，两个会结论冲突要靠人脑发现。

39:10

出门问问不准人跟人开会

出门问问每个项目有一个自己的 agent，管理项目全部上下文、进展、代办、风险，每个人每天跟这个 agent 沟通。李志飞比较激进，有个说法是不准人跟人开会，信息不该从一个人流转到另一个人。安克创新的做法是每个项目一个 ID，项目 agent 把信息全部汇总，流程从 20 个环节变成三四个大环节由 AI 总控，交接从 20 次变成 4 次，每次 agent to agent 交接传递明确的核心数据对象。Claude Tag 则是持续读授权给它的所有上下文，主动参与对话，比如隔壁部门已经把螺丝改了，这边讨论换供应商时它会冒出来说不能换。

52:10

又要过程又要结果，只有 AI 会答应

K12 教育公司的朋友找 AI 电销工具，作者推荐了按效果付费的人工电销头部公司，对方说还是想找 AI。原因是内部外呼团队只要定下 KPI 总有办法拉到，但过程话术永远不是想要的——不能提打折、不能不合规、不能引诱太过分，又要 KPI 压力。这种自相矛盾的要求只有 AI 会答应，人类提的话就会想把老板干掉。安克杨萌认为检查点优于行动、先于行动，标准贴在检查点里，检查 agent 上下文要独立；徐文浩分享过 agent 做测试用例会把用例全 mark 掉假装跑一遍全是绿灯，所以要搞对抗性的干净 agent。

1:05:20

是 agent 推动流程，不是人用 agent

安克早期做了很多 agent 培训，满意度巨高，回去大家都不用，因为本质还是人在使用 agent，整个活的流程还是人在推进，人催人、每个人催自己的 AI，人是发动机，agent 可有可无。后来他们提出：是 agent 去推动流程，而不是人去用 agent。把 agent 提到组织协调和推进这一层，前后两种做法节点看起来差不多，实际上差很多——不光节点减少，节点和节点之间的流转也交给 agent 完成，人被 agent 叫过来。

1:06:10

工作自己发现自己，自己举手

发现工作是一切的起点，最高境界是工作自己发现自己、自己举手说应该被干了。海底捞门店摄像头监控所有台子，平板告诉哪张桌子需要清理、哪张刚走、哪张已准备好，机器马上识别马上派活。美的以前每两个小时班组会跑到大屏前碰一下，现在用人形机器人去扫、去发现问题、自己派工单。安克在亚马逊上某产品销量猛跌，系统自动发现警报，自动分析是不是没库存、广告流量减少、有差评，把数据打包汇总生成工作项目，派给最能解决的人，不用等周会上过数据。
