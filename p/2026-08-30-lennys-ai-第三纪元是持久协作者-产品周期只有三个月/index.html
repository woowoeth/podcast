AI 第三纪元是持久协作者，产品周期只有三个月

OpenAI 产品负责人 Tara Seshan 断言，AI 产品正从聊天、代理走向持久协作者，构建必须按两到三个月的模型能力设计；未来工作是掌舵而非划桨，写作即思考永不上自动化。

AI 第三纪元：持久协作者

Tara 将 AI 产品演进分为三个纪元：第一纪元是聊天，第二纪元是与代理协作，第三纪元即将到来，是与一个能与你并肩完成事情的持久协作者共事。她强调，构建产品时既不能基于当前模型能力，也不能基于对一年后模型的预测，而应基于两到三个月的模型能力，因为两种极端都会失败。

— Tara Seshan
11:06

未来工作是掌舵而非划桨

Tara 认为未来工作将更多是「掌舵」而非「划桨」：代理负责执行，人类负责方向。掌舵的抽象层级会越来越高，但最终仍需人类做出有主见的决策。她强调，即使掌舵的层级上升，人类在关键节点上的判断和问责仍然不可替代，这既是责任也是价值所在。

— Tara Seshan
29:14

ChatGPT 与 Codex 融合

Tara 解释 ChatGPT 的「工作模式」底层是 Codex，但 UI 不同。产品北极星是让用户无需选择，系统自动为任务选择合适的工具。她强调「完成优于完美」，即先让用户用上，再根据反馈修正；快速迭代比打磨更重要，并说「这是模型有史以来最差的时候」。

— Tara Seshan
39:21

Codex 口碑逆转的真相

主持人观察到 Twitter 上对 Claude Code 和 Codex 的讨论风向在过去几个月发生转变，更多人开始倾向 Codex。Tara 回应称，Codex 团队一直保持用户导向和快速迭代，内部运作方式没有改变，只是市场和用户逐渐意识到这一点。她认为变化不在团队，而在用户的认知。

— Tara
53:30

写作即思考，永不上自动化

Tara 区分「写作即思考」和「写作即报告」。前者她绝不自动化，因为这是整理思路的关键；后者她完全交给模型。她建议写文档到 70% 就找人反馈，而不是追求完美。在 OpenAI，她仍写大量文档，但主要是为自己，因为长文档不再是思考深度的信号。

— Tara
1:02:43

产品营销契合被低估

Tara 在 Sutter Hill 学到最重要的一课是：产品市场契合固然重要，但她低估了「产品营销契合」。在构建产品之前，就应该通过大量推销来打磨叙事和定位。她认为出色的产品营销工作可以决定公司成败，并提到 Mike Speiser 在这方面无人能及。

— Tara
