续航数据和续航体验不划等号

明超平在 OnePlus 做产品时发现，纸面续航数据最漂亮，用户反馈却不好。原因是用户只在两个区间对电量敏感：95%-100% 拔下手机那一刻，以及 5%-0% 最焦虑的时候。苹果最后 5% 电量特别耐用，是因为那不是真实数据上的 5%，可能是 10%，用足够多的电量缓解焦虑。很多公司把续航设计成线性直线，理想状态应该是 S 型曲线。体验是主客观一块的，不是纯数据导向。

— 明超平
37:42

字节方法论会磨灭灵光一现的创意

明超平认为字节的数据驱动体系在拉高整体平均水平，让刚进来的校招生一星期交出 80 分结果，因为 AB 实验已经附下了 20%，你再怎么蠢也不会把它上线。但它抹灭的是最顶级的 100 分天才的灵光一现创意——iPhone 的多点触控屏、特斯拉，这些颠覆式创新都验证不出来。他把数据比作开车的后视镜：可以看到过去走过的路，但没法指引你往前开。

— 明超平
1:13:18

token 消耗速度才是 AI 时代的关键指标

2025 年春节后，明超平失眠时问自己：假如我是 VC 看 AI 产品，应该看什么？DAU 是从移动互联网时代来的，今天不一定还是关键指标。他得到的结论是看 token 的消耗速度。后来看到 Manus 的访谈，发现不谋而合。但他今天又迭代了：消耗越大不一定越好，更往前推一步是追求每个 token 的价值，叫 per token valuation。比如用一百万 token 写个网站，可能很多 token 是浪费的，好的 agent 应该用更少 token 写出网站。

— 明超平
1:16:33

壳被低估了，应该叫容器和环境

明超平认为壳这个词被大家低估了，他更愿意叫容器和环境。环境是人的反应器——同样一个人，去大排档吃烧烤和去高档法式餐厅，行为、说话方式甚至声音都会不一样。只给用户一个 prompt 框是不负责任的，因为用户真的不知道拿这个产品干什么。Midjourney 早期用户输的就是 a dog、a cat 这种短句，今天 500 个词的 prompt 是在 discord 频道里演化出来的，用户看到别人的作品、复制别人的 prompt、再二创，这个过程交换了所有人怎么用这个产品。

— 明超平
1:21:18

Coding 发展和当年 Camera 类似

明超平把 coding 的技术发展比作手机 camera 的发展。早期聊相机是拿着单反、调 ISO 调快门速度的人，但手机上出现 camera 后，出现了一帮新的人群叫手机摄影师。今天 coding 也一样，以前不会编程就无法 coding，今天 web coder 自然语言编程出现了。第二个变量是增速非常快，当年手机 camera 出现后一天产生的照片量级从 100 万张到 1000 万张到 1 亿张，指数级上升。趋势变量早期都是一帮新的人群出现，并且增速非常快。

— 明超平
1:36:13

Agent 生态像新加坡和美国两种国家

明超平用国家比喻 agent 生态：一种是非常独裁专制的国家，运行效率极高但强人政治；一种是民主制国家，共和党民主党来回 battle，修条铁路可能修二十年。背后是两种理念——追求上限和保住下限。对应到 agent，一种是一个 agent 调度所有其他垂直 agent，另一种是一堆垂直 agent 来回调度。他更倾向于后者，因为如果把 PageRank 变成 agent rank，最大的问题是把所有 2C 公司都变成 2B 公司，会受到反抗。

— 明超平
1:53:17

下一个 OS 应该是活的，界面实时生成

明超平认为今天操作系统的所有界面是固定好的死的，是程序员提前写好的，每个流程都是点个按钮就跳那个界面。但下一个 OS 应该是活的，所有界面是实时生成出来的，基于你当时的任务场景。比如开车时那块屏展示什么，和电脑上不一样，甚至开车开的时候和停的时候长得不一样。开会时为什么不会实时生成一个界面，既可以看到字幕，也可以记笔记，还可以看到进展。这需要一套 coding 引擎，未来打开网站的两秒钟里除了数据传输，还有界面实时渲染生成。

— 明超平
2:33:44

创业像下围棋，重要的是下棋顺序

明超平把创业比作下围棋，围棋里有个东西叫打谱，一盘棋下完之后复盘，把棋谱摆在面前分析。他强调重要的不是最终的棋谱长什么样，而是它下棋的顺序。不能今天看到抖音长这个样子、微信长这样子，就做一个一模一样的东西出来，因为那第五十步如果你下错了，可能就没有第一百步了。做产品优先级就是顺序的一种重要体现：什么东西做，什么东西不做，什么东西能三年后做，什么东西今天必须做。

— 明超平
