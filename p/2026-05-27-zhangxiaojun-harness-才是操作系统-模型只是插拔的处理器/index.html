没有 Claude Code，Anthropic 是另一家公司

雨森认为 Anthropic 被担心成「卖 API 的公司」时，真正的转折是 Claude Code。它带来大量高质量使用数据，数据回流让 coding 模型更好，形成数据飞轮。而 Codex 后来涨得也猛，说明 Claude Code、Codex 本质都是 Harness——不是有了强模型就能把 API 卖出去，用户要的是一个产品，不是 API。

— 戴雨森
23:17

Anthropic 的收入不是回报，是客户的投入

雨森把链条拆成投入、产出、结果三步：买 Token 是投入，做出软件是产出，软件卖钱或降本才是结果。Anthropic 收入大涨让很多人以为回报问题解决了，但这是把问题下推给了它的客户。他反问：一个公司突然多十倍工程师，收入会大涨吗？目前没观察到结果端的大幅提升，因为缺的不是程序员，是不知道该做什么。

— 戴雨森
37:14

壳早就不是壳：model、harness、context、runtime

雨森用 F1 打比方：模型是车手，Harness 是保养换胎让它留在赛道里的一整套。分层是模型、context、工具与 agentic loop、runtime/sandbox。OpenClaw 之所以惊艳，是给了模型很多权限，还有心跳机制每 30 分钟检查有没有没做完的事。这些机制讲出来都简单，但让模型在长任务上完成得更好。价值越来越多在模型外面包的这几层壳里。

— 戴雨森
52:25

Harness 更像 OS，模型更像处理器

广密说模型公司是新生代 OS，雨森不同意：Harness 本身更像 OS，模型像驱动 OS 的处理器。Windows 时代你可以插 Intel 也可以插 AMD，哪个便宜好用用哪个；现在用户也可以给 Harness 插拔模型。做 Skill 的人不用处理怎么跟模型通讯，就像 Windows 出现后开发者不用 handle 硬件，只 handle API。

— 戴雨森
59:20

agent 之间可能出现网络效应

过去 AI 一直没有好的网络效应，因为六个月前你用 Claude Code、我用 Claude Code 没有本质差别，没理由交换。但现在 Harness 里沉淀了各自的 context 和 skills，同一个任务给不同人的 agent 做结果不同。于是可能出现「我的 agent 雇佣张耀俊的 agent」：付 1 万块，1000 块是 token 价值，9000 块是对方 agent 积累的专有知识。这种价值网络有点像电商，但还很早。

— 戴雨森
1:21:26

你原来的护城河会变成软肋

移动互联网的超级应用把用户圈在 APP 里形成闭环，但如果用户的 agent 访问不到封闭 APP 里的信息，这个闭环就变成束缚。微信不开放，飞书开放还出了飞书 CLI，于是人有动力把工作群从微信迁到飞书——在微信里聊 agent 看不到，在飞书里聊 agent 看得到。同时大公司对安全质量要求高，而 OpenClaw 这类产品没有历史包袱，可以针对前沿用户设计更 AI native 的交互。

— 戴雨森
1:28:51

AI 像外星人来到人类世界，分三步

第一步让人类拥有更多更好的 agent（Claude Code、Codex、Manus 都在做）；第二步让 agent 适应人类的数字世界——人类的数据世界是为人类设计的，GUI、验证码、信用卡原本都是用来挡 Bot 的，现在要给 AI 发卡、让 agent 平等注册使用服务；第三步是建设 agent 专属的数字世界，比如 agent 之间的支付是高频、小额、多对多的，可能根本没有卡的概念，而是 CLI 或 API。每一步都是产品机会。

— 戴雨森
1:38:51

下一个字节可能长得不像字节

雨森说很多 AI 应用是「AI 的信息流」：一打开也是信息流，用户单列双列刷 AI 产生的东西，本质是把新技术包进字节最擅长的壳里，再比推广分发。在字节的游戏规则里打败字节非常难。OpenClaw 是另一种形态：没有自己的应用，连阵地都没有，但活在每个地方。把上个时代的成功范式搬到 AI 时代，等于跟冠军正面竞争。

— 戴雨森
