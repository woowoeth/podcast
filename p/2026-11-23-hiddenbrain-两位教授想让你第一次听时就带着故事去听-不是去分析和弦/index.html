19:05

一堂「证明音乐很主观」的课失败了

音乐心理学家 Lisa Margulis 在课堂上放一段学生没听过的瓦格纳歌剧前奏曲，本想证明每个人的联想都不同，结果第一个学生说「海盗」，第二年她改用纸条匿名收集答案，打开第一张还是「海盗」。这促使她花了十年时间设计实验，证实对从未听过的乐曲，陌生听众也会产生高度一致的具体联想。

— Lisa Margulis
25:40

大脑在追踪声音与情境的统计关系，不只是追踪下一个音

Margulis 认为以往的音乐认知研究只关注听众对「下一个音是什么」的预测，但真正重要的是大脑同时在追踪一种声音模式在过去生活里反复出现时所对应的情境。这解释了为什么一段从未听过、甚至风格完全陌生的音乐，也能瞬间唤起具体而一致的画面——是统计学习，不是巧合。

— Lisa Margulis
34:25

中国侗寨实验戳穿了「普世联想」的假设

团队特意跑到中国一个很少接触西方媒体的侗族村寨重复实验，发现当地人同样能很快产生共享的联想故事，证明联想的「一致性」本身是普遍的认知现象。但具体内容却因文化而异：同一段美国听众普遍联想到「独自在家被凶手跟踪」的音乐，在侗寨听众耳中变成了「在户外和朋友玩耍」。

— Lisa Margulis
36:42

音乐里也有「母语者」和「双语者」之分

在芝加哥的实验里，只熟悉西方古典乐或只熟悉印度古典乐的「单一音乐」听众，对自己熟悉的风格记忆更好、情绪反应更强；而两种都熟悉的「双音乐」听众对两种风格都有强记忆和强反应。更惊人的是，婴儿本能分辨巴尔干民乐那种罕见节拍，但在芝加哥环境下到12个月大就会失去这种能力——只需一周被动播放巴尔干民乐就能找回，成年人单靠被动接触却做不到。

— Lisa Margulis
46:25

把同一首曲子播两遍，多数人会说第二遍更好听

Margulis 在课上给学生放两段「不同演奏版本」，实际上是同一份录音，让学生投票哪个更好。多年来大多数学生都说第二遍更有表现力、动态更戏剧化。揭晓真相后，学生才意识到纯粹的重复聆听本身就会改变人对声音的感知，这也是她用来论证「重听音乐会深化体验」的核心证据。

— Lisa Margulis
1:16:52

爱尔兰给2000名艺术家发基本工资，结果更敬业也更健康

研究发现职业艺术家平均幸福感更高，但焦虑和抑郁也更高，原因是艺术一旦变成谋生手段，就会被收入不稳定、职业可持续性等压力缠绕，形成一种「被不稳定化的心态」。爱尔兰试点给2000名职业艺术家发放基本收入、不用操心赚钱只管创作，结果不仅公众参与度提升，艺术家心理健康也改善，这项计划后来被定为永久政策，苏格兰也表示要跟进。

— Daisy Fancourt
1:24:13

手工艺是最容易进入「心流」的活动，不是冥想

一项让受试者记录两周内两万两千段体验、涵盖两百多种活动的大型研究发现，最容易诱发心流状态的活动是手工艺。这解释了为什么在癌症治疗陪护住所里，哪怕只是围桌折纸、画画、拼图，也能让陪护家属暂时从「接下来会怎样」的焦虑里抽离出来。

— Daisy Fancourt
1:28:22

公园跑的成绩变慢了，这是好事

过去十年里 Park Run 这类群众跑步赛事完成时间变慢，不是因为大家跑得更慢了，而是因为越来越多本不自认是「跑者」的人也开始参与。Fancourt 希望艺术也能复制这个逻辑：重点不是「你画得好不好」，而是「你参与了没有」，评价体系应该从作品质量转向参与本身的健康收益。

— Daisy Fancourt
