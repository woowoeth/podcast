模型公司是挖矿的，产品公司是炼矿的

最好的模型拿走了最大的流量和收入，但挖矿的窗口正在缩短：从两年到九个月再到三四个月。基础模型公司开始端到端做 Agent，应用公司的成本劣势是结构性的。

广密第七次季报，这次浓墨重彩讲产品。分化、全家桶、垂直整合、L4 体验、挖矿窗口，五个判断都有具体数字支撑。

核心论点 · 点时间戳可跳到原声

4:07

模型公司在分化，只有两家还在做通用

广密最突出的感受是模型在分化：往后走可能只有 Google Gemini 和 OpenAI 两个真正做通用模型，各项能力全都要，从多模态到推理模型到 Coding 到 Agentic 到 2C，甚至 Google 想做世界模型。其他模型公司都开始分化到各个领域——Anthropic 分化到 Coding 和 Agentic，Mira 创办的 Thinking Machines Lab 想做多模态和下一代交互。这个分化不是被迫的，是主动的 Bet。

— 广密
5:07

Anthropic 是被正反馈推着 all-in 的

Anthropic 几乎放弃了多模态、放弃了 2C、也没有推独立的推理模型。广密判断转折点在 24 年夏天推 Claude 3.5 的时候，外界开发者的反馈给了团队很多正反馈，整个团队更加 all-in 到 Coding 和 Agentic。他用了「Reward Hacking」这个词——管理团队可能也被 Coding 叫 Reward Hacking 了。这个 Bet 的回报是：23 年底 AR 可能还不到一亿美金，24 年可能 9.5 亿美金，有人猜测 25 年年化收入会超过 120 亿美金，甚至 26 年可能三四百亿美金。

— 广密
7:09

只做 Coding 撑不起宏大叙事，所以这里有非共识

广密认为 Anthropic 的核心就是赌 Coding 和 Agentic。如果 Anthropic 不专注，像 Google 和 OpenAI 一样既做多模态又做 2C，撒胡椒面的战略是很危险的。但反过来，如果 OpenAI 和 Google 举全公司之力全力 all-in 做 Coding，Anthropic 也有危险。问题是 Google 和 OpenAI 的 CEO 或管理层被问到要不要只 all-in 到 Coding 这一个能力向，答案都是 No——大家觉得只做 Coding 不足以支撑宏大叙事。所以 Coding 这里依然有很强的非共识。

— 广密
8:09

Coding 和世界模型其实是一件事

Google DeepMind 的 CEO Dennis 描述 Google 的世界模型 Genie 3 是一个孕育 AGI 的、能无限扩展的虚拟子宫。广密说 Coding 也是虚拟子宫，世界模型和 Coding 其实是一件事，只是不同的路径。他的论证是：人和动物的区别是有语言和创造或使用工具的能力，语言和 Code 加上 Agentic 工具能力，就能让 Agent 在数字化世界实现人在电脑上手机上操作的所有行为——这已经是 AGI 了。做一个前端网站或 PPT，过去要很多轮跟工作室沟通，现在是几百步上千步的 Agentic 推理，最后 Coding 生成 HTML。

— 广密
10:10

Thinking Machines 是全球历史上最贵的天使轮

Mira 之前是 OpenAI 的 CTO，她创办的 Thinking Machines Lab 是全球历史上最贵的天使轮，100 亿美金估值融了 20 亿美金。广密认为三个点最关键：第一，这是硅谷过去几年最强的出场团队，可能比今天的 xAI 还要强，更像是 OpenAI ChatGPT 或 Post Train 加上核心 Infra 团队的分拆——Meta 小扎要花 15 亿美金挖其中的一个人，那个 Infra 的 Lead 直接被拒绝了，一个人都没有被挖走。第二，Mira 是 OpenAI 最核心的管理层，知道哪些做得好哪些做得不好。第三，Mira 可能是全球范围内适合做苹果公司 CEO 的，产品为先的理念 match 苹果。

— 广密
15:14

xAI 的超大算力没有拿到 payback

马斯克之前最大的 bet 是单一超大的集群，算力能带来模型的根本性提升。但广密说目前没有得到 payback——超大算力只能说是不掉队的基础，但不一定能让 Grok 反超。Grok 今天还在摸索自己的生态位：做 chat 赢不了 ChatGPT，做搜索前面还有 Google 和 perplexity，做 coding 也有 Anthropic，做多模态做世界模型，感觉 Grok 今天是没有想清楚的。广密猜测 xAI 可能很大概率未来半年一年要并入 Tesla 一体化，因为一个独立的 AI Lab 没有一个大腿其实很难的。

— 广密
29:21

横向全家桶和纵向垂直整合，两个趋势同时发生

广密说今天有两个最明显的趋势。一个是横向的全家桶：ChatGPT 你花 20 块钱或者 200 块钱买一个账号，已经包含了 chat、搜索、coding、agent、workspace PPT，等于买了十几个套件，这对做单一垂直能力的套件很不利。另一个是纵向的垂直整合：Google Gemini 从 TPU 芯片到 Gemini 模型到上面的 agent 应用，还有 Google Docs、Chrome 浏览器、安卓操作系统、YouTube 视频，可以做超级继承。所以 Google Gemini 在 model 上落后几个月没问题，何况它现在还不是落后的。

— 广密
40:25

挖矿的窗口在缩短：从两年到九个月到三个月

广密让同事专门拉了一下窗口期，发现窗口是在缩短的。Perplexity 的窗口是两年——模型公司自身开始加联网搜索平均晚了两年的，但今天 ChatGPT 加了联网，Perplexity 依然还在保持高速增长，每个月可能还有几千万的新增用户。Cursor 是因为 Claude 的 Sonnet 火起来，从 Cursor 开始有热度到 Claude Code 发布，其实就九个月的时间。Minus 的窗口是今年三四月份发布，ChatGPT 跟进类似的产品大概是三到四个月。从两年、一年、九个月、三个月，窗口是在缩短的。

— 广密
47:34

Cursor 的长期竞争是很悲观的

广密说如果让他作为 Cursor 的团队，今天要跟 Claude Code 长期竞争，其实是很悲观的。假设 Cursor 现在马上能复现一个 Claude Code 一样的产品效果，那要面对这么高的亏损率——产品定价就是 200 一个月，但很多用户有时候几天就用到几千块的 token，甚至 1 比 3 甚至 1 比 10 的 token 的亏损率，成本是吃不消的，很容易被拖死。而且这里还没有谈后面怎么优化模型能力，如果 Cursor 想向下面改某个能力或者数据的分布，模型训练能力是跟不上的。

— 广密
52:44

重新看好 Google，是因为规模效应

广密这次很大的变化是重新看好了 Google。他的观察是 ChatGPT 和 Google 最终的产品形态上肯定都是殊途同归的，就像小红书那样融合了搜索、短视频、朋友圈。另一个猜想是 ChatGPT 后面肯定会做广告，因为最近刚招了一个新的商业化的 CEO，之前是 Instagram 的 CEO，在之前是 Lead Meta 的广告系统。也许未来头部的用户收费很贵，200 块钱一个月、2000 块钱一个月，但付费用户可能也就 3% 到 5%，95% 以上的用户都是免费的，那就要看广告。Google 还是全球最好的广告平台。

— 广密
