VC 的贵不体现在你差的时候

肖弘把资本定义为工具，而且是一种很贵的集资手段。他给出的机制是：VC 的贵不体现在你不好的时候——按条款美国正统的融资是不用还的——而体现在你好的时候，你牛逼了，付出的代价更大。由此推出他对竞争对手的判断：那家公司融了更多钱，就必须向投资人交付更大的故事，于是被迫做错的事。他的结论是，哪怕最后你的事情更小，也比做一个错的事情好很多，CEO 应该有勇气做正确而小的事。

— 肖弘
44:45

预判大厂：外挂一定会被干掉

企业微信开放接口时，肖弘判断外挂一定会被平台治理掉，但没人知道什么时候。他的推理是：只想客户，客户当然希望发越多广告越好；但想平台，就知道微信生态不能乱，腾讯一定会限制。于是关键动作不是等外挂被干掉再开发，而是打提前量——因为开发一个 SCRM 工具至少需要一个月，等到那天再动手就晚了。他总结成一条可复用的原则：面对一个你几乎认为一定会发生、但不知道何时发生的事，在能承受的成本范围内越早准备越好。

— 肖弘
1:11:08

Jasper 庆祝扩招时，他看到了裂缝

肖弘研究 GPT-3 API 上跑得最成功的公司 Jasper，看到创始人写公开信庆祝公司从 9 人涨到 200 多人。他的判断相反：管理本身是反规模的，人越多破事越多，这家公司的执行可能会变慢。第二个判断是 Jasper 定价太贵，而按计算机产业的朴素认知，能力和 API 成本会大幅下降，所以应该会出现偏个人、professional 而非企业采购的市场。第三，ChatGPT 出来后他确认对话式才是大众对 AI 的想象。三条加在一起，让他在 ChatGPT 发布之前就决定立项 Monica，内部目标只是一个月赚 5 千人民币。

— 肖弘
1:28:22

买来的增长会让团队学不到东西

收购 ChatGPT for Google 之后，肖弘没有把它改名成 Monica，而是重新做一个产品。原因不是品牌，而是增长反馈：ChatGPT for Google 每天有自然流量带来的几万新增，如果团队守着它，某位同事找到每天带来 200 新增的方法也不会觉得了不起，团队的知识学习速度会变慢。重新做 Monica，大家自己找到一点点新增都会开心，从而学会怎么在海外做增长和运营。同时买来的产品是资产，导量不会有损失，而投广告是丢到水里的钱，会让人犹豫。

— 肖弘
2:14:52

新时代的安迪比尔定律

肖弘用半导体产业的安迪比尔定律解释 AI：不管安迪造了什么，比尔都会吃掉它。放到今天，模型能力一直在进化、越来越便宜，但壳也需要进化。Cursor 成立很早，真正为人所知是 Cloud 3.5 Sonnet 发布之后——模型能力提升带来了它产品能力的迭代。如果没有 Cursor，Cloud 3.5 Sonnet 在 Claude 里也能写代码，但不会那么流畅。所以模型能力外溢之后，需要第三方厂商把用户可感知的价值呈现出来，这是创业者可以定义的部分。

— 肖弘
2:26:59

把思考过程放出来是体验创新

肖弘认为 DeepSeek 全球爆火不只是技术强，而是把技术上的创新点以用户可感知的方式展示了出来。他引用 Publicity CEO 的说法：AI 时代两个巨大的体验创新，一是联网回答时标出引用来源，二是把 LM 思考的过程展示出来。OpenAI 的 o1 其实也有思考，但 o1 要收费、只展示简化版，很多人根本不知道这回事，所以错过了这个体验创新。DeepSeek 免费、完整展示，加上模型质量确实拉到第一梯队，老家朋友都能感受到代际差别。

— 肖弘
2:36:05

Agent 应该自己写代码调 API

肖弘描述被闪电击中的瞬间：用 Windsurf 的 Yolo 模式时，Agent 说它要去 GitHub 上下代码、搞一个事情再写。他意识到它居然在用工具。由此推出 Agent 的架构：一个虚拟服务器、一个浏览器，能自己写代码调用 API。因为人类很多知识和服务不是通过 API 而是通过 web 调用的，所以必须带浏览器；因为要执行命令行、装库，所以需要云上的虚拟机，坏了无所谓，任务结束可以释放。他还指出 Yolo 模式让用户填 yes 是甩锅——小白用户根本不知道 yes or no。

— 肖弘
3:12:32

用博弈思考，而不是逻辑推导

肖弘区分两种思考方式：逻辑推导是「百度有最好的算法工程师，所以百度一定会把推荐做掉」；博弈思考是因为你的出现和其他 player 的出现，整个环境不一样了。他举例：如果没有 DeepSeek 这一波，大家不会思考开源；如果最初做 ChatGPT 的是第三方公司，OpenAI 也许会选择做纯粹的 platform company 而不是 consumer app company。他前一次创业做企业微信 CRM 也是同理——因为生态里有人做得很好，企业微信就说交给生态去做。所以创业者要尽量让自己成为那个重要的变量。

— 肖弘
