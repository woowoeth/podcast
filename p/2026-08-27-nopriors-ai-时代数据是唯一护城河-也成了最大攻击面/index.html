AI 时代数据是唯一护城河，也成了最大攻击面

模型和算力正被商品化，企业真正值钱的资产只剩自有数据；Google 花 1000 万美元买破产航司数据只是开始。同时，拥有合法权限的 AI agent 让数据安全威胁从人转向非人类，旧基础设施正在失效。

核心论点 · 点时间戳可跳到原声

3:13

数据成为唯一护城河

Eon 创始人说，模型和算力正变得相对标准化，几乎零切换成本；企业真正值钱的东西只剩自有数据。两天前 Google 花 1000 万美元从 Spirit Airlines 破产资产里买走数据，传闻另一个竞标者是 MerCore。数据不再只是备份，而是可以被拿去训练模型、理解业务、继续变现。这种「买破产公司数据」的交易会越来越多，数据正变成企业估值里最核心的部分。

7:49

好数据比模型更缺

要训练出真正能工作的 agent，需要高质量真实数据，而不是合成数据。头部模型公司几天前刚发布法律数据集，但市面上可用的好数据集很少。创始人的观察是：企业年度报告等公开数据也能拿来训练「公司如何运作」的模型；任何声称不接触真实世界就能做出重大 agent 的说法都不可信。新方法要么造出更好的合成数据，要么拿到真实数据后脱敏。

11:18

数据被锁在业务单元里

数据团队负责人被 CEO 要求激活数据，但第一步永远是找不到数据：业务单元各自为政、20 年旧系统没人懂、还有连了电的「史上服务器」没人敢关。即便知道数据在哪，要绕过安全、合规、生产停机去抽取，成本极高。Eon 的解法是把发现、分类、语义层和持续接入做成自动化，不碰生产系统，也不让敏感数据外流。

15:00

Agent 威胁是加速版攻击

过去的安全威胁来自人类。Eon 在 AWS 时遇到的大客户，因为资源没有正确打标分类，60% 环境被勒索软件暴露。现在同样的威胁来自 AI agent：它们带着合法权限访问数据库，很快就能删掉一张表。检测和恢复的方法论相似，但发生速度极端。企业既要防外部攻击者，也要防内部那些已经被批准运行的 agent。

21:04

人人能造 Agent，规则失效

非技术人员用 Lovable 这类工具给自己的业务搭 agent，把公司数据放进去，完全不知道安全、合规和数据最终会被谁使用；这些 agent 还会互相调用。组织里因此出现一套新行动者：不受组织规则约束、不一定跑在组织边界内，却握着敏感数据。创始人认为「全员都是构建者」既是好事也是坏事。

25:00

旧管道撑不住 Agent 数据

旧数据基础设施是为「事先想好的单一目的」设计的：信用卡交易被抽取、放某处、下次再处理，段与段之间没有上下文。AI 时代相反，团队只要能把数据聪明地聚在一起，就能问出前所未有的问题，比如把纽约爱吃汉堡和爱吃披萨的两份名单合并。同时 agent 也在疯狂制造数据，噪声和油并存，旧工具已经不够用。

28:14

AI 迁移比云迁移更失控

云时代的大迁移要搬数千到数十万台服务器，技术和人力成本都很高；AI/agent 时代的转型速度快得多，客户已经在失去控制，甚至因为怕数据泄漏、IP 外流而暂停推进。关键差异是产品感知：云对普通人抽象难懂，ChatGPT 之后每个人都立刻理解 AI。CEO、董事会、股东一边推动 AI，一边又恐惧 AI。

31:22

PLG 回归，大厂靠并购 AI 化

过去创始人认为 PLG 对 DevTools 大多不成立，现在变了：Cognition 这类公司先 PLG 再转入企业，创业公司派强工程师带现成方案进场，把一到两年、更长的流程压缩。另一个新模式是传统大公司自己 AI 化太慢，索性买下一家 AI 公司改造成自己的增长引擎。创始人的判断是这才刚刚开始，多数公司仍在 AI 采用早期。

NHI / Non-Human Identity非人类身份
机器、服务账号、AI agent 等非人类实体的身份，需要像员工身份一样治理权限与审计。
PLG (Product-Led Growth)产品驱动增长
由产品本身完成获客、激活与转化，而不是靠销售主导。
Data Foundation数据底座
