3:55

模型厂商的 token 毛利在挤压三方 agent

三方 agent 应用活跃数比巅峰可能跌了三分之一。原因不复杂：模型厂商 token 毛利很高，可以用很低的成本提供 token，而三方是向它买 token 的，没法打价格战。更关键的是模型越强，Harness 的差别越小——之前 Manus 在上面打很多脚手架让它变厉害，模型一升级，脚手架 80% 就废了。写 PPT、写文档、做调研这类普通任务，Harness 好一点坏一点差别不大。

6:13

OPC 不成立，先卖别攒技能

很多人失业了管自己叫 OPC，问最重要是搭 Harness 还是干嘛，回答是都不重要，重要的是找到谁给你付钱。大部分 OPC 在那边自嗨，提笑了这个提笑了那个，然后去哄骗一批也想做 OPC 的人来给他钱，但大家都没钱了，无源之水撑不下去。干活和把活转变成钱是两件事，难的是后面那件，而大部分人原来也不是做销售出身，没有在市场上直接卖过东西。

12:24

信息差比你想象的大：上门帮老板装 Codex

一群企业家觉得你是 AI 专家，问的问题却是 Codex 怎么安装、信用卡怎么存。有人专门找了一个英国回来的小朋友，上海地区负责上门，其他地方负责远程视频，帮他们刷卡、下载软件。很多看起来非常高科技的公司，创始人平时是用豆包的，工作当中很多也在问豆包。传统企业利润薄，副总可能才 50 万，研发负责人可能才 80 万，懂还要加上表达能力，老板也不信他，外来的和尚反而容易被信。

19:08

FDE 的宿命：填完缝隙就消亡

FDE 可能不是一个长久的业务，更像在这个阶段去填补企业渗透 AI 缝隙的过程，随着慢慢填补了，FDE 这个时针就消亡了。因为模型能力越强、产品越完善，就应该是公司自己内部的员工拿着一个 agent 自己喷一下。所有公司要解决的并不是 AI 问题，还是业务问题——餐馆要有客人来花钱吃麦。外行 AI 的人不了解餐馆怎么运营，餐馆不了解 AI，你想挣钱就拼命去了解餐馆，慢慢帮他把缝隙填补完。

21:05

AI 转型是政治问题，老板需要一把外面的刀

公司内部的人熟悉公司，为什么还要请麦肯锡讲道理，这很多时候是政治。AI 革命的是自己：对员工是来抢饭碗的，对管理层是来抢权的，让自己开刀自己这事很难。老板虽然看起来很有权威，把下属喷得像狗一样，但已经干涉不了业务，甚至不敢把那个高管开掉。高管会非常直接地跟推 AI 转型的 HR 负责人讲，这件事情对我的好处，两个人都很熟，说不出来没有。所以要借刀杀人，不是能力上做不到，是位置上做不到。

28:09

蒸馏是 ROI 极高的数据获取方式

蒸馏肯定很有作用，是 ROI 非常高的一个。让 AI 写代码跟人写代码效率差多少倍，这就是准备数据的效率差距。获取训练样本的方式是自动的，只要有足够多的账号跟足够多的钱，它是横向扩展的；而人要人去写数据是手动的，且不一定能横向扩展。从后训练角度获取 bootstrap 数据，两边效率差别非常大。至于字节为什么没做出 SOTA，不一定跟蒸馏有关，Google 也没出来，而且字节跟 Google 都所有事情都做，可能期望做全模态统一的模型，早期融合会让问题更复杂。

38:17

DSH 不是好 Harness，但是好内核

好的 Harness 或 Agent 都做了非常多的取舍，有很强的 opinion：Codex 有插件机制但自己的 Agent loop 改不了，Pi 认为不需要很多 tool，OpenCloud 重视通过各种 IM 接入。DSH 的做法是万事万物皆可改，所以它肯定不是一个好的 Agent 或好的传统 Harness，喷它的人说做太烂了完全同意。但它的路径有价值：为什么整个 coding harness 是一个静态的东西，为什么不能这一轮对话是这样、那一轮是那样，整个 agent 运行时是不是也在动态发生改变。

43:27

可塑性软件：每个人都要一个自己的厨房

海外把这个词叫 Wearable Software，可塑性软件。有两张图很说明问题：一个是制作室，下面是厨房，每个厨子或电工的工作间长得都不完全一样，装备、布局、习惯用的锅铲调料都不一样。每个人用 Agent 也是这样的，有人用 Cmax，有人用 Codex 客户端，有人用 Herdr。原来这个需求很难满足，大家捏着鼻子用不同软件组合，在非常小的地方很难定制；今天根据我的需求写代码定制变得没那么困难，但也不应该从零做，而是基于某一个软件或内核改成自己需要的东西。

56:35

AI 原生组织：让 AI 来推进工作闭环

比较有效的不是改组织让你更好地用 AI，而是用 AI 来完成组织的职能，AI 是组织的竞品。具体做法：在飞书里报 bug，Agent 会自动去看线上日志、看当前代码库来回答，知道你是谁、你的邮箱、你账户实际的运行情况；每天扫线上报警发到不同群；每周自动扫代码哪些模块重复了、需要重构了、哪里文档没有更新对齐，AI 把改完的发一个 PR 给你看。设计师要改界面，研发把 codebase 给他自己改，加检查门禁只能提交分支，工程师帮他把环境设置好，本地就能模拟线上服务器。
