20:32

新互联网第一次有了 context

Tristan 把传统互联网和 AI 互联网的区别说得很直接：过去的互联网是低维标签化的信息，Tinder 上你划一千张卡片、匹配三十个、用同样话术聊几百轮，最后拿到几个有效连接，中间全靠人类做工。新的互联网第一次有了 context——大模型能真正理解几十万上百万 token 的长内容。所以 AI 时代的社交网络是很多节点，每个节点背后有大量 context，如果能让这些 context 流动起来、连接起来，就是一个全新范式的 AI native 社交网络。

— Tristan
23:05

最难的是双重冷启动

Elys 的产品设计难点被 Tristan 概括为「双重冷启动」：一方面你的 context 要从零到一个足够像你的状态，另一方面网络里的人也要从零到一个足够多的状态。他认为 context 的冷启动反而更难，因为用户可以通过运营方法同时涌入，但让一个完全不了解产品的用户、在还有防御心理的情况下交出初始 context，是最难的。所以产品前期最大的设计难点是：在用户流失之前，一定要让他感受到 context 飞轮带来的收益。

— Tristan
36:56

AI时代唯一重要的事是做自己

Tristan 把这称为自己的「暴论」：在 AI 时代，你接下来唯一需要做的、唯一重要的事情就是做自己，更严谨的说法是「构建主体性」。因为很多事情会 agentic 地发生——你给一个标题，它就能写出跟你很像的文章；在 Elys 里分身等级足够高的人什么都不用干，真人就跑过来了。当 AI 能力不断增强、能自动帮你干很多事时，你唯一要做的就是告诉它你到底是谁、你的价值观和审美是什么、你过去沉淀的资产是什么、你现在想要什么。

— Tristan
45:17

夜壶：交出隐私换真实连接

Tristan 用一个夜壶的故事说明为什么交出隐私是值得的：他有个朋友晚上上厕所必须用夜壶，这个习惯很隐私也很怪癖。后来这人交了个女朋友，女朋友走进卧室看到夜壶，直接惊了——因为她自己也用夜壶。Tristan 说，假设你在 Elys 里找女朋友，如果你很真实地做了自己，在茫茫人海中就有那样一个人也干这件事，在基于 LM 的推荐系统里他们最终会被匹配到一起。你交出了隐私、做了真实的自己，反而收获一段很好的真实连接。

— Tristan
54:35

没有一家公司真正沉淀了你的 context

Tristan 的判断是：中国并没有一家公司拥有很多真正的 context。微信、小红书、抖音拥有的是你的低维数据——兴趣标签、搜索记录，但微信没有跟你对话的过程，小红书年度诗篇写得很一般，因为它只有低维标签。他拿 EVE 的专属情歌做对比：那是基于用户几千轮对话写的，所以非常高位、非常打动人。他反问：现在你能不能找一个地方，用几万 token 把「你是谁、你想要什么」表达出来？并没有。

— Tristan
1:00:02

传统互联网等于低维标签加人类做工

Tristan 给了一个公式：传统互联网 = 低维标签 + 人类做工，然后得到连接；AI 社交 = 高维 context + AI 的 agentic 做工，最后的环节再交给人去处理。中间那一大部分的商增被 AI 做掉了，这是最大最大的不同。他由此提出「低商世界」——很多科幻小说里喜欢写的那种更高级文明、更美好的世界，因为那里有更少的摩擦、更妙的连接。

— Tristan
1:07:40

分身综合症：分身比真人更锐评

Tristan 观察到一种现象叫「分身综合症」：你的分身在 Elys 里天然更 real、更直白，会直接锐评，说一些你现实中绝对不会直接跟这个人说的话。当你看多了这种话、认可了这些锐评，它会反馈到你真实的人身上——你在微信里的聊天状态也突然变得很锐评，脱口而出一句很锐的话，对面反而觉得有意思、挺 real。他举了个例子：投资人老板在 Elys 发湖边风景，下属的分身直接在下面留言「哟老板，您这班上得可真好啊」，阴阳怪气，但两人关系反而变得融洽自然。

— Tristan
1:28:10

智能是平权的，context 不平权

Tristan 说他一直不认可「模型即产品」：AI coding、视频生成 agent 这类围绕模型滴水果实做的产品，核心还是 leverage 底模能力，窗口期一过就会被更 all in one 的端到端底模覆盖。但 EVE、Elys 不是模型即产品，核心由产品驱动，模型只在最后提供智能。他有一句话：将来智能是平权的，但是 context 不平权。所以真正有价值的事情还是你积累了多少用户的 context。他明确说完全不用自己训模型，不会去 pre-train 底模，但会做 post-train 和情感 COT 这类针对性工作。

— Tristan
