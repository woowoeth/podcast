智库该补的是前瞻研究的空当

Khan 说，当年在乔治城 CSET 做半导体政策研究时，AI 政策还没人关心，有大把时间做面向一两年后的前瞻研究；如今每天都有AI新消息，反而没人愿意沉下心做这种工作。他认为新智库 CTS 要补的就是这个空当：一是做一两三年后真正管用的政策构想，二是把研究建立在真实的供应链细节上——从制造设备到 token 到机器人，因为物理世界的东西是可预测的、经得起深挖，不像空对空的政策辩论。

— Saif Khan
7:04

美国领先8个月，没人说清机制是什么

外界常说美国模型能力领先中国约八个月，但 Khan 说这个数字背后的机制几乎没人讲清楚——多少来自训练更大模型，多少来自中国公司靠蒸馏或强化学习获得的能力提升，美国进展加速或放缓又会如何传导到中国。他举例，当 GLM 5.3 flash 被曝出用数十万亿 token 训练时，舆论立刻说「出口管制没用了」,但这个判断对不对，其实缺乏系统性的解释支撑。

— Saif Khan
13:21

DUV光刻机是中国最后一块啃不下的骨头

Khan 说，EUV极紫外光刻之外，DUV浸没式光刻是目前仍在用于制造先进芯片的次优技术，华为造7纳米芯片靠的就是它。全球只有日本和荷兰两个美国盟友能造这类机台，是美国手里最有效的卡脖子工具——中国造不出来，而且是整条半导体设备供应链里最难实现自主可控的一环。报告测算，中国要到2030年代中期左右才可能有商用的本土DUV机台，是供应链里最后被攻克的环节。

— Saif Khan
17:30

管制留了口子，中国机台存量已悄悄翻倍

2023年管制生效时，低一档的DUV浸没式机台仍被允许卖往中国，当时中国存量约170到180台，此后这个存量已大致翻倍。报告建模测算：如果现在彻底切断DUV出口，到2030年代中期，美国每年能产出约10亿颗H100等效AI芯片，而中国本土产能会被锁死在千万颗量级；但如果继续放行这些机台，两边产能区间可能会重叠，等于把整个领先优势拱手让出。

— Saif Khan
31:18

软件智能爆炸之外，机器人是被低估的变量

Khan 认为，未来几年AI世界真正的转折点，可能不是软件上的递归自我改进，而是物理世界的自动化——AI与机器人结合，规模化部署机器人去学习制造，最终可能形成自给自足的供应链。这个方向目前在华盛顿几乎是空白地带，他说整个政策圈里认真研究机器人与AI交叉问题的人一只手数得过来，中国那边的研究更是几乎没有，这会是美中AI竞争下一个关键节点。

— Saif Khan
33:27

AI政策分裂成安全派与扩散派两种世界观

Khan 把AI政策的分歧归纳成两种思维：「安全心态」认为最重要的行动者是研发前沿模型、可能带来灾难性风险或改变世界权力平衡的少数AI公司，这种变化往往发生在现有建制之外；「扩散心态」则认为真正重要的是AI被广泛采用后与既有制度的共同演化，核心是财富再分配和AI在经济体系中的角色。他强调这两者不是对立，而是都要解决——即便防住了生物武器风险，只要没回答人类在AI经济里扮演什么角色，问题就还没解决。

— Saif Khan
44:00

编程智能体把智库人力压缩到一小部分

Khan 说，过去九个月里 Claude Code 和 Codex 这类编程工具，让CTS这样的小团队能查询大量数据、快速做深度分析，DUV报告能达到的技术分析深度很大程度上得益于此。他认为过去需要十五到二十人的智库团队，现在一个更小的团队就能做到同等的产出密度和分析深度，这也是CTS愿意在这类工具上大举投入的原因。

— Saif Khan
55:36

他不是RSI怀疑论者，但不知道曲线会怎么弯

面对「你比Dario Amodei更怀疑递归自我改进」的说法，Khan否认自己是怀疑论者：他认为AI公司完全有能力判断自己是否在实现AI研发自动化，未来几年很可能真的大幅自动化一大部分AI研究。他真正的不确定在于另一个问题——自动化AI研发究竟只是勉强让人类维持住现有的能力增长曲线，还是会把这条曲线进一步推陡；今年已经出现自主网络攻击、智能体能力、解出Navier-Stokes这样的千禧年数学难题等里程碑，但自动化研发在现实世界的实际影响，他认为现在还很难判断。

— Saif Khan
