NVIDIA: Data Centers Aren't Cost Centers—They're Token Factories

Moore's Law's physical dividend ended long ago; NVIDIA pursues ‘extreme co-design’ across five layers—energy, chips, infrastructure, models, apps—to aggressively boost tokens per watt and per dollar.

Data Centers Shift from Cost Centers to Token-Printing Revenue Engines

The keynote opened by clarifying the paradigm shift: data centers previously ran IT applications and were pure cost centers; AI factories must generate tokens efficiently to create revenue. This positioning shift is the starting point for all subsequent engineering decisions—energy, chips, cooling—and every optimization targets raising tokens per dollar and per watt.

4:09

Moore's Law's Physical Promise Broke Two Decades Ago

Transistor counts do keep doubling, but Moore's Law originally included a physical and economic promise of doubling at the same power and cost—this part stopped working after Dennard scaling ended around 2005. This is the fundamental reason NVIDIA bet on accelerated computing and rewrote single-threaded applications as GPU-parallel applications, not mere marketing narrative.

— Kevin Deierling
6:13

Mixture-of-Experts Models Triggered Token Consumption Jump

Model parameter scaling at roughly 10x annually is a stable trend, but Mixture-of-Experts (MoE) models a year and a half ago created an inflection point: models began ‘reasoning’ and generating one output token internally creates up to 100x more tokens. The arrival of agents will accelerate this demand further, which is why NVIDIA must continuously drive down cost per token.

— Kevin Deierling
13:31

Energy Storage Flattens AI Training's Power Spikes

During AI training, thousands of GPUs synchronize collective communications like a giant computer, and power load swings wildly like a downpour, damaging supply transformers. NVIDIA uses energy-storage systems like DSX Flex/DSX LPS to store excess power and release it during peak demand, flattening the consumption curve. This single optimization enables 40% more GPU deployment from the same 1 gigawatt power, directly translating to 40% more revenue.

— Kevin Deierling
16:38

Inference Complexity Demands Multi-Chip System Design

Industry once assumed inference would be simpler than training, but MoE models impose heavy demands on both NVLink vertical scaling and cross-rack horizontal scaling, and agent workloads raise stakes further. NVIDIA's answer couples Rubin GPU and Vera CPU tightly via high-performance, cache-coherent chip-to-chip interconnect, then scales within cabinets via NVLink and across data centers via Spectrum-6, claiming this delivers 10x token throughput and one-tenth the per-token cost.

— Kevin Deierling
19:43

Copper Signal Degradation Drives Optical Interconnect Adoption

To save power, NVIDIA insists ‘use copper when you can’, but high-speed signals travel only meters over copper cables, so they cram GPUs into the same cabinet with liquid cooling. Counterintuitively, even within a rack, signals degrade crossing those short copper traces on PCB, requiring re-amplification and optical-module drive; co-packaged optics (CPO) switches solder optical transceivers directly beside the ASIC, eliminating that degradation and saving tens of megawatts in AI factories—power saved becomes tokens generated.

— Kevin Deierling
21:46

Agents Loop AI Output Back as Input, Bypassing Humans

Agents' essence is AI looping its output back as input, no longer relying on human prompts—humans are too slow, AI too fast and too ‘impatient’, creating AI-to-AI dialogue chains. Vera CPU is built specifically to run these agent toolchains: planning, coding, summarizing and compressing results, directly raising demands on memory and interconnect bandwidth—from 800G to 1600G/second.

— Kevin Deierling
22:46

Agent Memory Architecture Demands Dual-Layer Storage Design

NVIDIA analogizes KV cache as agent short-term memory, files and objects and vector databases as long-term memory, and designed CMX (short-term) and STX (long-term) reference architectures accordingly. This new architecture reportedly delivers 5x token throughput and 5x efficiency—storage no longer merely stores data but directly determines agent ‘thinking’ speed.

— Kevin Deierling

Glossary

Extreme Co-Design
Simultaneous cross-layer optimization across five layers—energy, chips, infrastructure, models, apps—rather than optimizing any single layer alone.
Co-Packaged Optics (CPO)
Packages optical transceivers directly beside the switch chip, reducing signal loss and power consumption on PCB copper traces.
KV Cache
Intermediate state saved after a large language model processes text, equivalent to an agent's ‘short-term memory’.
Mixture-of-Experts (MoE)
Architecture that dynamically invokes partial ‘expert’ sub-networks during model inference, significantly increasing internal token consumption.
NVLink
NVIDIA's high-bandwidth interconnect technology between GPUs within a cabinet, enabling multiple GPUs to run cooperatively as one computer.
