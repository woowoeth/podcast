Xiaomi's Three Chips: Trading Resources for Time, Betting on an On-Device AI Paradigm Shift

Xiaomi releases three Xuanjie chips in one go, aggressively betting on memory interconnect, 3D stacking, and an all-AI architecture, trading resources for time to bet on an on-device AI paradigm shift and vertical integration capabilities, but still clearly lagging top-tier chip companies.

ChipsXiaomiXuanjie3D stackingOn-device AIVertical integration
This episode offers an in-depth analysis of the technical choices and strategic logic behind Xiaomi's three chips. It is information-dense, with clear analogies for key technologies like memory interconnect and 3D stacking, making it worthwhile for chip industry professionals and investors following Xiaomi.

The argument · tap a timestamp to hear it

3:02

Chip capability is about system definition, not IP self-reliance

To judge whether a company can make chips, don't just look at how many IP blocks it hand-crafts; look at how much system definition it controls. Xiaomi's Xuanjie O1 uses ARM IP for CPU and GPU, but system integration and physical implementation are done in-house. Apple and Qualcomm excel at yearly iteration and continuous tape-outs, which latecomers lack. Xiaomi doesn't have a decade to learn slowly, so it chooses an aggressive path, advancing multiple high-risk technology lines simultaneously.

— Lao Shi
6:04

O1's poor energy efficiency stems from a missing shared water tank

The Xuanjie O1 lacks a system-level cache (SLC), causing power consumption to spike under heavy GPU load and hurting energy efficiency. An SLC is like a shared water tank in a neighborhood: the closer data is to the compute units, the faster the access and the lower the power. The O1 has many GPU cores but limited DDR bandwidth, so many cores wait for data, and utilization stays low—this is the bandwidth wall. The O3 adds a 16MB SLC, splits it into multiple cache blocks distributed across the chip, and designs an on-chip network scheduler to handle data consistency and access conflicts.

— Lao Shi
10:07

ARM's generic bus forces Xuanjie to build its own

ARM's off-the-shelf CHI+CMN solution is too generic, retaining compatibility and redundancy that hinder customization for Xuanjie. The O3 instead develops its own X-Ring unified fabric, compatible with CHI but defining its own interconnect protocol, along with a custom high-speed network hub and memory controller. This reduces protocol conversion overhead, letting data decide cache placement and paths based on needs. Xiaomi claims protocol conversion overhead drops by 75%, and static access latency is 82 nanoseconds, 32% lower than the O1 and even lower than Apple's A19 Pro.

— Lao Shi
12:09

Compute bottleneck shifts from matrix multiply to vector operations

The O3 adds AI units to every subsystem—CPU, GPU, ISP, etc.—so computation happens where data resides, reducing data movement. The NPU core count drops from 6 to 4, but Tensor compute rises to 200 TOPS, because Xiaomi judges that large-model bottlenecks are expanding from matrix multiplication to vector operations like Softmax, quantization, and KV cache. The vector unit area is similar to the Tensor unit, with 6.8 times the multiply-accumulate units of the O1, and it introduces an SMT-like architecture, similar to CUDA, to handle irregular parallel tasks.

— Lao Shi
15:11

Chips and models should be co-defined by the same company

Xiaomi collaborates with MEMO to compress INT4 weights to 5 bits using a 5-value quantization method, with almost no accuracy loss, reducing memory bandwidth and capacity needs by 30%. The 3-billion-parameter MEMO model runs on the O3, with prefill performance up 40% and decode up 45%. This chip-model co-definition capability is the closed-loop advantage of vertical integration—no need to wait for others to define models and then adapt.

— Lao Shi
16:11

3nm performance is squeezed out standard cell by standard cell

The O3 uses the more mature N3P process, delivering 5% higher performance at the same power and 5%-10% lower power at the same frequency. Xiaomi also does extensive process optimization: self-developed standard cells increase from 480 in the O1 to over 2,400, covering various chip units; power delivery buffers are compressed, letting power and signals route from the middle of modules, boosting transistor density by 5%. The CPU shifts from a 4-cluster to a 3-cluster 10-core all-big-core design, with single-core performance up 31% and multi-core up 60%, surpassing the A19 Pro.

— Lao Shi
19:13

Near-memory computing pushes phone memory bandwidth to 1.22TB/s

The Xuanjie O100 uses wafer-level 3D stacking: one compute wafer and two memory wafers stacked vertically, interconnected via hybrid bonding, forming a near-memory computing architecture. It uses thousands of shorter, denser vertical connections for high bandwidth, with lower energy per bit shift—similar to HBM for phones. Data: 28,762 data connections, bandwidth 1.22TB/s, far exceeding the tens of bits of traditional SoC-LPDDR connections. The compute layer has 14 independent cores, each paired with a RISC-V processor for control.

— Lao Shi
21:17

CXMT's value lies in co-definition, not speed grades

Xiaomi partners with CXMT to debut LPDDR6, reducing reliance on Samsung and SK Hynix. Even if CXMT offers the 10.667Gbps entry speed grade, Xiaomi can compensate for peak rate gaps with wider channels, larger SLC, and a custom memory controller. More importantly, the two co-validate and tune from the design stage, jointly defining a Chinese mobile memory subsystem solution. For CXMT, this proves its high-speed I/O and physical layer capabilities, earning a seat at the next-generation mobile memory table.

— Lao Shi
23:18

Xiaomi bets not on chips but on a time window

First, it bets on an on-device computing paradigm shift: AI's weight in SoCs grows, phones become AI interaction gateways, and Xiaomi aims to stand in the definer's position. Second, it bets that vertical integration becomes a core competency for device companies: generic chips can't meet the fragmented needs of human, car, and home scenarios, so Xiaomi must own its compute architecture. Third, it bets on an uncertain time window, trading resources for time to compress the catch-up cycle, preferring to bear engineering risk rather than watch the window close.

— Lao Shi
26:20

Xuanjie closes faster, but none of the three thresholds are crossed

Top-tier SoC companies need three capabilities: custom CPU/GPU microarchitecture, custom 5G baseband, and continuous multi-generation tape-outs with tens of millions of shipments. Xuanjie currently meets none, still clearly behind the first tier—it just closes faster. What truly reshapes the industry isn't a single stunning chip but the sustained iteration capability built by a group of companies. Xuanjie's larger significance is proving Xiaomi's chip efforts haven't stopped and that it's moving forward with Chinese chip industry partners.

— Lao Shi

Glossary

SLC / System-Level Cache
A cache shared by multiple compute units within a chip, like a neighborhood's shared water tank.
Hybrid Bonding
A wafer-level 3D stacking interconnect technology using direct copper-to-copper connections, offering high bandwidth and low power.
Near-Memory Computing
Placing memory and compute units close together to reduce data movement distance, improving bandwidth and energy efficiency.
Bandwidth Wall
A performance bottleneck where data movement capability limits performance, so adding more compute cores doesn't help.
SMT / Simultaneous Multithreading
A parallel processing architecture that manages multiple task groups simultaneously to improve compute unit utilization.
