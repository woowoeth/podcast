Dirk Bockstegers 1997-01-07

Apple's NeXT Acquisition Event: Jobs Says Three-Person Garage Team Can Beat a 150-Person Corporation

Apple's management compared Mac OS to a Cessna that needs a new engine, while OpenStep, demonstrated on stage by Jobs, enables developers to leap from the fifth-floor level to the twentieth-floor level—that's the real reason for acquiring NeXT.

Apple historyNeXT acquisitionSteve JobsOperating systemsDeveloper platformsRhapsody
This is a recording from Apple's 1996-97 NeXT acquisition announcement. While the information density isn't high, it offers Jobs' own words on platform strategy and developer productivity—recommended for those interested in Apple and NeXT history.

The argument · tap a timestamp to hear it

0:14

An old foundation can't hold new features; Mac needs complete redesign

Apple's management compared Mac OS to a Cessna that needs a new engine. Starting with 128K in 1984, every feature added since has been squeezed in. The company swapped processors from 68k to PowerPC just to keep up. That's not how you design a platform. Apple needs a Boeing-777-class modern operating system architecture from scratch.

5:31

NeXT outperformed other options by fifty percent on sixty technical criteria

Apple established sixty evaluation criteria for the new operating system core. Beyond minimum requirements like preemptive multitasking, memory protection, and SMP, the company sought standout factors to excite developers. NeXT's technology scored roughly fifty percent higher than other options across these criteria, becoming the direct basis for the acquisition decision.

9:48

Developers building from a higher platform level create more ambitious software

Jobs used a building metaphor: DOS puts developers on the first floor, enabling them to build four-story applications. Mac's toolbox elevates developers to the fifth floor, letting them build eight-story apps like PageMaker—impossible on DOS. But ten years later, Windows caught up to the fifth floor, erasing Mac's advantage. A new system must lift developers higher still.

— Steve Jobs
13:02

Three-person teams using OpenStep now match 150-person corporation quality

Throughout history, breakthrough software like PageMaker and Illustrator emerged from small companies, not large ones. OpenStep's real innovation is enabling a two- or three-person garage team to deliver software in six to nine months with the functionality and reliability of a 150-person corporation. Apple's goal is to spawn a hundred new software companies built on this technology.

— Steve Jobs
14:09

Mach OS has been proven in production enterprise systems for over five years

The Mach OS foundation has already operated as a mature Unix-like system in critical enterprise workloads for more than five years. It supports multitasking, multithreading, symmetric multiprocessing, and rapid driver development. It's also cross-platform: a single binary automatically recognizes and runs on different processor architectures without maintaining separate applications for 68k and PowerPC.

— Steve Jobs
16:18

NeXT incorporates the two PARC innovations Jobs missed when designing Mac

Jobs recalls visiting Xerox PARC in 1979, so captivated by the graphical user interface that he never looked further. Years later, he realized PARC had also shown him two other things: object-oriented programming and networking. Both are core to NeXT's design from the start—designed to fix the one fatal flaw in Mac: it was never built for the network.

— Steve Jobs
24:49

Interface Builder eliminates eighty percent of the code developers otherwise write

On stage, Jobs used Interface Builder to drag sliders and text fields into connection without writing or compiling code—objects communicate at runtime directly. The fastest code to write, the cheapest to maintain, and the code that never breaks for users is code they never have to write at all. The goal is to eliminate eighty percent of repetitive boilerplate from every application, freeing developers to focus on the twenty percent that actually creates value.

— Steve Jobs
32:24

Apple will ship Rhapsody every six months to accelerate innovation

Apple named the new operating system Rhapsody and committed to a six-month release cycle. The developer version ships mid-year with Blue Box features still in development. The first production release comes at the next Apple conference, six months later. A fully unified version ships six months after that, with performance for legacy applications equal to or better than today.

Glossary

Blue Box and Yellow Box
Compatibility environments: Blue Box runs legacy Mac OS applications; Yellow Box is the native NeXT-based API for new development.
OpenStep
NeXT's object-oriented application development framework and the technological foundation for Apple's new Yellow Box API.
Interface Builder
NeXT's visual development tool enabling drag-and-drop object connections to build interfaces without writing or compiling code.
Rhapsody
Apple's new operating system codename following the NeXT acquisition, released on a six-month cycle.
