OpenAI is eliminating model selectors: the future is one resident agent

OpenAI is merging Codex, ChatGPT, and Dots into a single resident agent without a model selector. The goal: users never choose models, never juggle multiple agents, just state what they want to do.

3:10

Dots is a resident agent without a model selector

Tibo says that regardless of the name, the core is breaking free from being ‘pasted onto a specific client’: a resident agent that's always online, knows all your goals and preferences, and can be invoked from any screen—taking notes in meetings, following up on emails and messages. You don't keep watching your laptop or phone; it appears when needed and disappears when not, rather than dragging users around like a brick.

— Tibo Sottiaux
7:19

Codex and ChatGPT will merge, capabilities extended to 1.2 billion users

Tibo says Codex and ChatGPT's chat and work modes will be unified, eliminating users' burden of choosing between ‘fast but limited’ and ‘powerful but slow’. All Dots capabilities will integrate directly into ChatGPT to ‘lift the floor’—raising the baseline experience for 1.2 billion users—while Dots itself deliberately has no model selector; the only configuration is which channels to connect.

— Tibo Sottiaux
11:24

The plugin ecosystem is the real hidden blockbuster in today's launch

When asked which announcement was underestimated, Tibo pointed directly at ecosystem opening: last year's ‘Sign in with ChatGPT’ began as mere ‘virtual handshakes’ with founders like Perplexity and OpenCode, then evolved into formal multi-partner integration. Now plugins can reach 120 million users' distribution channels, and popular, high-usage plugins will receive revenue sharing—something not even mentioned in the keynote.

— Tibo Sottiaux
20:09

An agent caught a production incident five minutes before going live

Before the Dev Day broadcast, Tibo's dot recognized it was launch day, ChatGPT production had a system issue, and the event had a live demo—these things were connected—and warned him five minutes early that ‘production is down’, even offering to help. Tibo's response was ‘thanks, but I don't think you're at that level yet’, then he contacted the engineering team. He sees this kind of cross-scenario correlation as genuinely impressive.

— Tibo Sottiaux
21:36

Dots doesn't run on your device—it connects multiple machines like an octopus

The fundamental difference is that the execution harness doesn't run on your own device; instead it can simultaneously connect any number of machines—your laptop, or possibly dedicated hardware like a Mac mini. Specialized ‘expert dots’ handling sensitive tasks run with extra guardrails and monitoring on isolated hardware. In theory, a single dot could eventually control ten devices at once, like an octopus.

— Tibo Sottiaux
23:39

Fast typing is becoming worthless; founder mindset and taste are gaining value

Tibo says fast typing as a skill is becoming obsolete, while taste and user-first thinking are gaining value. Many former founders and serial entrepreneurs now stand out; OpenAI currently has over 120 former founders on staff, which he calls ‘a mega startup’. Role boundaries are blurring too—previously being design-only or engineering-only felt limiting; now is the time to ‘shine’.

— Tibo Sottiaux
30:45

Most internet traffic will soon come from agents—products need to handle the load now

Tibo believes the notion that ‘most internet behavior will be performed by agents’ hasn't been properly priced in yet. He cites Notion: after building MCP, suddenly large numbers of agents poured in making calls and doing actual work, traffic exploded, and the system faced real pressure and economic consequences. His conclusion: whether to build a human-usable interface can wait, but scaling for agents is inevitable and most products haven't truly thought it through.

— Tibo Sottiaux
33:55

Safety investment: monitoring agents costs as much compute as the main agent

On AI risks, Tibo says ‘staying at the frontier’ for him means investing early and investing more than he thinks ‘should’ be necessary: alignment, safety, and guardrails get continuously increased investment. Compute dedicated to ‘second-order monitoring’ of the main agent's behavior is growing substantially—checking whether it's taking high-risk actions or showing signs of prompt injection. He also mentioned the team built Astra 6.1 but chose not to release it, a decision he's proud of.

— Tibo Sottiaux

Glossary

Dots
OpenAI's new resident agent product, no model selector, configuration limited to which channels to connect
MCP
Model Context Protocol—standard connectivity protocol letting third-party apps and plugins integrate with ChatGPT and various agents
harness
Agent execution framework—the underlying scaffolding code that runs agents, calls tools, and decouples from specific devices
prompt injection
Attack where adversaries craft inputs to trick the model into executing unintended, unprivileged actions
Astra
OpenAI's internal code name for the safest, best-aligned model
