Human Click Data Is a Bug: Agent Search Needs New Indexing and Pricing

When search's customer shifts from humans to agents, click data stops working and indexing, pricing and business models all have to be rebuilt; Parag offers a new framework with the quality/cost/latency triangle and Shapley.

The argument · tap a timestamp to hear it

1:00

You can't just hand human search to agents

The premise behind Parag founding Parallel is that agents will use the web to get work done more than a thousand times as often as humans do. So you can't just port the old browser and search engine model over to agents; you have to rebuild a search infrastructure for agents from indexing and ranking to the business model. He thinks many former moats are losing their force.

— Parag Agrawal
7:18

The opponent isn't Google, it's people manually organising the web

Parallel didn't build a full index on day one; it shipped a search agent product first, using one-to-ten-minute deep research to compensate for insufficient index coverage. The opponent it chose was "hiring people to manually organise web data", not Google's index scale. Early customers used it for insurance underwriting, claims processes, sales data cleaning and financial modelling data collection, gradually building the index up.

— Parag Agrawal
14:46

The hard part isn't crawling pages, it's compressing to 1000 tokens

Parag doesn't call Parallel a neo lab, because the output isn't a model but a complement layer to models. The core problem is condensing a trillion web pages into the right 1000 tokens, which requires a lot of research on retrieval, ranking and memory hierarchy, finally compressed into a very small ranking model. Every advance in model capability unlocks more scenarios Parallel can serve, rather than making Parallel's work pointless.

— Parag Agrawal
26:06

Model companies' pretraining crawlers can't become a real-time index

Model companies can own search directly, or they can buy it. Parag doesn't think pretraining crawlers are naturally equivalent to a real-time index: model companies skip slow JavaScript pages because the token payoff isn't worth it, whereas Parallel is a completionist, willing to fill in those corners. Today Parallel works with Google Cloud, becoming one of the search and grounding providers for Gemini/GCP enterprise agents, and enterprises can choose between Google search and Parallel search.

— Parag Agrawal
28:19

The search volume multiplier is in developers, not the chat box

A typical search agent will do 5–20 searches even when answering within seconds; ChatGPT triggers 5–10 searches per prompt turn at the medium setting, and hundreds to thousands when turned up. The faster multiplier comes from developers: one customer managing a credit portfolio of ten thousand small businesses switched from a monthly manual risk assessment to running automatically every week, and the search volume multiplier reached hundreds of thousands to a million.

— Parag Agrawal
34:49

Agents have no conversion rate, so ad pricing loses its foundation

Most Google queries lose money, and a minority of queries pull the profit back, relying on differential pricing of limited human attention. Once agents go online in place of humans, that premise starts to collapse: agents have no conversion rate statistics, and content owners still setting business models around "human visits" will find every way to keep agents from crawling. If AI inference volume grows 7x each of two years, while fixed-price licensing contracts don't grow, the existing content business will be hurt at renewal.

— Parag Agrawal
42:55

To know what content is worth, take it out and run it again

To decide what a content source is worth, you can remove it from the corpus and run the agent to see how much output quality drops; if spending one more cent of compute can restore the quality, that source's value is close to one cent. Shapley value is the mathematical framework that formalises this intuition, but computing it fully is extremely costly — allocating 1 dollar might burn several dollars. Parallel's approach is to train a good estimate from data and models rather than doing exhaustive simulation.

— Parag Agrawal
53:11

The web's endgame is you call me, not I go look it up

Parag's endgame has three layers in progression: the first is agents using the web as a tool; the second is multiple agents and subagents collaborating on long-running, compute-heavy tasks; the third is the web shifting from "I go look it up" to "you call me". Much future work will be triggered by changes in the world: satellite imagery changed, customer reviews changed, another agent finished computing — Parallel's role is to continuously allocate compute across the whole web, watching for changes on behalf of all its customers.

— Parag Agrawal

Glossary

Shapley value
A method in cooperative game theory for allocating total value by marginal contribution; used in content pricing to estimate the incremental value of a given content source.
grounding
Linking model outputs to external reliable data sources, reducing hallucination and supplementing real-time information.
fresh index
Separately indexing newly published and fast-changing web pages, avoiding mixing them with the full offline index.
memory hierarchy
Storing the index in layers by access speed and cost, so that limited compute can hit results within a latency budget.
