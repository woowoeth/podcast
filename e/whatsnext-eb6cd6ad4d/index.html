智能体支付已落地，但替你花钱还差三道坎

Clink 与 Visa 完成第一笔 agent 支付，行业却卡在信任、授权和商户就绪三道关；法币因消费者保护先跑通，稳定币还在解决不可逆。

Agent 购物的两种场景

高宁与 Patrick 把 Agent Payment 拆成两类。一类是用户明确需求的电商购物、服务预订，agent 帮执行，最终消费人还是人；另一类是 agent 在执行任务中自己产生的消费，比如调 API、买研报、下载资料，金额小但高频，需要在授权额度内自主进行。前者体量大、链路长，后者是新增场景，目前主要发生在用户与闭源模型（如 OpenAI、Claude）的对话里。

— 高宁
7:30

三道关卡：信任、授权、商户就绪

Patrick 认为当前最大问题不是技术，而是三个环节。第一，agent 的智力与推荐质量还没赢得用户信任，上下文懂你不代表懂你喜欢；第二，agent 不能被信任保管卡信息，一旦发生倒刷，责任要用户自己承担；第三，商户端对 agent 下单带来的客户关系归属有疑虑，且 agent 在普通用户中渗透率低，商家大规模投入的 ROI 不足，导致 merchant readiness 进展缓慢。

— Patrick
9:48

Clink × Visa VIC 第一笔交易

Patrick 介绍与 Visa 的合作：Clink 被定位为 Visa 全球生产网中的第一个 agent enableer。6 月底在博览会上执行了 VIC 的第一笔交易。流程是 agent 把用户上下文、授权额度和商品类型传给 Clink，Clink 记录为 mandate；agent 找到商品后，Clink 校验与原始授权是否一致，再向 Visa 申请一次性支付能力，Visa 核验后完成支付。这套机制把最终追责链路变得清楚。

— Patrick
12:57

法币优于稳定币的原因

Patrick 解释 Clink 选择法币而非稳定币的原因：法币体系中的消费者保护机制成熟，银行和卡组织对授权、争议处理都有完整流程，信任问题更容易解决；而稳定币一旦支付出去基本不可逆，消费者信心和持续信任都会受损。随后嘉宾补充了一个真实案例：有公司解雇员工后某个 token 一夜烧掉 600 多美元，无法追查，后来只能改为每人单独 API 以便追溯。

— Patrick
16:04

稳定币在做链上支付宝

高宁介绍稳定币赛道的进展。稳定币体系里，单纯的小额转账已经比较成熟，因为链上支付就是端到端转账。更有意思的是有人在尝试解决淘宝早期的问题：用户和商家互不信任。方案是用智能合约把钱锁在中立位置，确认交付后再释放给商家，解决「钱付了不发货」的不可逆问题。高宁认为小额高频的基础设施已不缺，缺的是场景丰富度和用户习惯的迁移。

— 高宁
23:24

Clink 是高速公路之间的匝道

Patrick 说 Clink 不是新修一条高速公路，而是去做路与路之间的匝道。用户可能从 OpenAI 的 ACP 协议来，商户却用的是 Shopify 或 Stripe；不同协议、不同支付公司、不同电商平台之间需要有人做转换和衔接。Clink 的策略是尽量兼容 UCP、ACP，并给 Shopify、Magento 等电商平台做插件，让商户低成本 onboarding，在现有 OMS 和订单体系不变的情况下变成 agent payment ready。

— Patrick
29:30

中国支付生态的独特路径

高宁说国内没有海外卡组织的倒刷/申诉体系，更多是客诉性质，责任归属不同。但国内电子支付普及率极高、基建成熟，只是时间问题。腾讯在做 Agent 卡，支付宝公布了 AMP 协议，但场景落地还没看到。主持人补充说微信 Agent 生态可能几个月内发布，正在和几个大商家跑，说不定第一个大规模 agent payment 会先发生在中国。

— 高宁
37:43

未来一年想看到的信号

Patrick 说两个信号：一是真的有用户因为 agent 找到了自己没想到的好东西，出现 aha moment，突破推荐算法「too well」的信息茧房；二是越来越多人开始调用付费的外部数字服务，而不是只用 token 本身。高宁则有个更个人的期待：他一直在用 GPT 聊自己的肠胃炎症状并得到益生菌推荐，但最后还得自己再去别的平台下单、开处方，他希望这个流程直接从对话变成下单、寄到家里，而且他判断国内会更快。

— Patrick
